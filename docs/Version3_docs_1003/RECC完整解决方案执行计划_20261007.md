## 1. 总体目标与推荐决策

按“正确性 → 专家能力 → 路由可学习性 → 预测收益 → 临床证据”的顺序恢复研究链路。先证明被校准对象确实存在可利用差异，再投入训练；不以路由分布变化、agreement 或显著性代替预测价值。

立即暂停原第二批权重、τ 和 Pair-RECC 搜索。首先完成源代码追溯、候选预测契约、梯度和诊断一致性审计，再使用已取得权重复评。当前不直接选择 ROI 重构、CPM-MoE 或干预预测。

推荐默认路线：修复与复评现有 one-step 设置；如果其可实现收益门不通过，转入冻结多步异构预测器的廉价检验；只有该检验通过才开发 CPM 专家。两者均无收益时，收敛到简单预测模型与有限的诊断定位。

## 2. 已知事实、待验证问题与当前状态

### 2.1 已知事实

- 五组实验均为 patch=4、seed=2024；test 为相同 225 名被试、3825 个 task，anchor 集合与三条 baseline 一致。
- D 相对 B：one-step MAE 改善 0.1745%，CPM H8 改善 0.1046%；rollout H16 MAE 恶化 2.3403%，FC MAE 恶化 1.8243%。这不是稳定的整体预测提升。
- E1 单步改善只有 0.0105%，仍得到未校正配对 p≈0.0086。统计显著不能作为继续投入的充分条件。
- E2 专家末层权重变大，而 decoder 可见方向的参数分量仍与其他组接近，支持零空间解释；尚未验证实际样本 correction。
- 五组 HAMD–PCC 与 HAMD–MAE 相关均弱且不显著。它们是误差关联指标，不能独自否定模型中的病理信息。
- E1/E2 最后保存最佳模型分别在 epoch 36/41，已经过冻结期和 dense warmup。
- 本地源码仍只有 TFM/FiLM；MoE/RECC 运行源码尚缺。十份 MoE 权重、评估结果和 E1/E2 日志已取得。

## 5. S1：工程正确性与对照修复

### 5.1 统一完整预测契约

以同一 context 和 RevIN stats 构造正式 mixture、单专家、pair 与 shared-only 输出：

```text
expert_delta_norm = decode(z_shared + expert_delta_z)
expert_state_norm = x_last_norm[:, None, :] + expert_delta_norm
expert_state_raw = denorm_with_context_stats(expert_state_norm)
```

公共转换函数负责形状、广播、affine、epsilon 和 no-RevIN。命名明确区分 residual、state、normalized 和 raw。不要使用 `denorm(delta_norm) + x_last_raw`；它可能重复引入偏置。

修复默认仅改变 candidate/diagnostic 口径。正式 prediction 若原来正确，其输出必须可复现。若发现正式路径也错误，另记录影响，不与候选修复混为一项。

### 5.2 必须补充的测试

| 测试 | 预期 |
|---|---|
| one-hot 路由 | 正式预测等于对应完整 candidate |
| 相同专家 | 全部 candidate 等于 mixture |
| 共享线性 decode、仿射 RevIN、权重和为1 | raw mixture 等于完整 candidate 加权和 |
| 全 residual 为零 | 等于 persistence |
| 病理 residual 为零 | 等于明确绕过病理分支的 shared-only 输出 |
| 非平凡 RevIN | 非零 bias、非单位 weight、不同 mean/std、no-RevIN 均正确 |
| 人工最佳专家 | 包含漏锚点会翻转排名的反例 |
| RECC-only backward | Router 可获梯度，expert/backbone/SC/CPM 不获 RECC 梯度 |
| task-only backward | 选中专家可获得预期梯度与更新 |
| 冻结阶段 | 参数组覆盖 Router/全部应训练专家，shared 分支冻结 |
| Top-1/Top-2 | 分别记录 task 与正则对 Router 的梯度；不预设 Top-1 task 非零 |
| diagnose 开关 | 同输入、状态和 RNG 的正式输出、task loss、梯度和单步更新一致 |
| mask/精度 | target、anchor、future mask 对齐；FP32/AMP 数值差可量化 |

diagnose 作为观察工具时不能额外影响 task dropout/RNG。优先同 checkpoint 离线诊断；若另算 teacher/coupling 概率，明确其 dropout 和梯度语义。

如果实际 Top-1 使用标准归一化且没有选择梯度，先正确标注它作为固定/间接分区实验。是否增加直通估计或其他竞争式训练属于新方法变量，不能伪装成工程 bug 修复。

### 5.3 统一 loss 与评估

- candidate、final 和 target 全部采用同一原始状态空间。
- 训练 competence Huber 与报告 MAE 分别保存，明确 Huber delta；不跨函数做倍数或 oracle 差值比较。
- 统一先被试内、再跨被试的主聚合口径，避免训练验证按 batch 平均影响微小收益的选权重。
- 按研究任务选择 val checkpoint：one-step 阶段用 one-step 指标；CPM 新阶段用预设轨迹指标，H1/rollout 作为约束。避免以含 RECC 的 total loss 选择跨 λ 的模型。
- 记录 dense/sparse、冻结/解冻和学习率实际状态；保留完整精度指标。
- 审计 r2e 模式下非零 pair weight 是否确实不生效，禁止隐含 pair loss。

上游全序列 z-score 与可能的双向滤波单独记录。若要开展严格在线预测结论，建立保留旧数据、独立版本的 context-only/因果预处理敏感性验证；不得在本次修复中覆盖原始数据或混入解释。

### 5.4 G1：工程验收门

完整契约、梯度边界、冻结覆盖和 diagnose 一致性通过；小样本正式输出可复现；candidate/loss/schema 元信息完整。数值容差由 dtype、变换 epsilon 与量级明确规定，不以放宽断言掩盖逻辑错误。

G1 不通过时只修工程，不进入研究训练。

## 6. S2：统一重评与历史结果重解释

### 6.1 重评范围与输出

先固定一小组 val 被试与 anchor 完成 best/last 重评，再运行完整 val；确认协议后才生成历史 test 口径修订结果。

保存以下数据：

- `expert_metrics_per_anchor`：subject、context、cutoff、HAMD、site、每个专家 MAE/Huber、最佳专家、平局标记、Router full probs 和实际 routing weights。
- candidate/mixture/shared-only 的完整 raw 输出，六组 pair 输出或可复算数据；受控存储，不提交含被试标识的大数组。
- latent correction、decoder 可见投影、raw correction 的距离/幅度和实际任务增量收益。
- 被试汇总、competence matrix、oracle、各 horizon、模式与精度元信息。

小样本 gradient/update 诊断与全量无梯度评估分开，避免长循环保存反向图。

### 6.2 必算指标

1. 逐样本专家损失极差及分位数、超过实践阈值的比例；区分它与专家平均损失极差。
2. 最佳专家在样本间是否切换、各专家是否有超过噪声水平的优势区域。
3. train/calibration 上选择的固定最佳专家、固定均匀混合、当前 Router/mixture。
4. 单专家 oracle、equal-weight pair oracle、实际 Top-2 配比和可行连续 pair oracle。
5. agreement、top-2 recall、regret、Spearman 与 q entropy；平局样本单列，不强制精细排名。
6. shared-only 与每个病理修正/mixture 的增量收益，以及 HC shared 分支漂移。

pair loss 必须从完整 pair prediction 计算，不能平均两个单专家 scalar loss。MAE 的 pair 权重可用一维凸优化/断点求解；将实际部署权重包含在候选集合。粗网格只能称近似 oracle，不能据其低收益强证伪连续可行路由。

oracle 使用未来真值，只能作为事后诊断。它不等于部署收益。单专家 oracle 可能比 mixture 差，负 gap 并不自动表示不存在 pair 收益。

### 6.3 区分修复评估与修复训练

无 RECC 的旧模型：若错误仅在无梯度候选诊断中，优先复评，不重复完整训练；若 diagnose 改变了更新/RNG，另判断训练对照是否需要重建。

使用错误 q 的 D：新 candidate 只能揭示该权重真实能力，不能把旧训练变成正确 RECC。保留“旧监督训练＋新口径评估”的标签；仅当收益门通过，才重训新监督版本。

### 6.4 G2：实践收益空间门

建议以主 MAE 相对改善 1% 作为筛选门槛，在约 0.075 的尺度对应约 0.00075；这是资源决策阈值，不是临床有效性标准。正式值在 train/calibration 和重复测量误差基础上锁定，不依据新 test 排名调整。

比较可行 oracle 与最强的已验证可部署参照策略；不是只与 persistence 比较。完整且足够精确的可行 oracle 空间若低于门槛，停止当前设置的预测型 RECC/Pair-RECC。若 oracle 有空间，进入 S3。

仅部分样本或粗权重网格未发现收益时，只报告“该检验未发现信号”，不宣称原理上无空间。

## 7. S3：检验差异是否能被输入预测

冻结 backbone、shared、decoder 和专家。用 train/calibration 的历史状态描述符和条件训练小型 Router，在 subject-disjoint val 上对比：固定专家、固定均匀混合、原 Router、新 Router与 oracle。

使用独立 calibration 或被试级 cross-fitting，减少训练集上的乐观 competence。所有状态和条件只包含推理时可获得的信息；未来真值只用于监督/事后 oracle，不作为 Router 输入。

oracle 有空间但 Router 无收益时，检查：

- 全脑 mean/std 是否丢失局部网络信息；只有确有能力差异时才试预设 network 统计。
- 最佳专家切换是否主要来自噪声或近似平局。
- 是否实际上某一个固定策略已足够，无需条件选择。

不把反复降低 τ 或增加 Router 容量作为默认补救。

### G3：可实现收益门

新 Router 必须在 val 上超过最强可部署对照及预设收益门槛；不得只满足 agreement 提升。稳定性约束同时检查，配对 CI 和有效样本比例一并报告。

没有可实现收益：停止该专家库的 RECC 训练，转入第 8 节的多步冻结库或结束扩展。有收益：选择一条 S4 路线。

## 8. S4：最多启动一个有限试点

### 8.1 路线 A：正确 RECC，优先保留原结构

适用：现有 one-step 专家库通过 G2/G3。

第一组比较仅为同结构、同初始化/HC 权重、同 split 的 RECC off 与正确 RECC on。固定现有主要超参，先不做 λ/τ 网格，也不加 pair。

保留 q stop-gradient 和 Router 输入 detach。可在独立对照中检验低收益样本降权：

```text
spread_b = max_i loss_bi - min_i loss_bi
a_b = clip((spread_b - delta0)/(delta1 - delta0), 0, 1)
loss_recc = mean_b(a_b * KL(stopgrad(q_b) || p_cpl_b))
```

delta0/delta1 使用 train/calibration 的 Huber 尺度；不能直接套用 MAE 的实践阈值。标准化分母增加训练尺度下限的选项单独验证，避免同时更改多项无法归因。全部 a=0 时 RECC 为0；记录有效比例、task/RECC loss 和梯度量级。

若能只校准冻结专家即获得收益，优先验证此低成本版本；联合重训另作比较，不默认共享分支必须解冻。

### 8.2 路线 B：两专家的受限 one-step 分工

适用：必须保留局部 transition 为研究核心，且有证据表明不同历史信息/局部函数约束能形成互补。

先两个专家，明确差别来自短/长历史视野、受限函数或 train-only 状态区域；同一 target、同一原始空间评估。共享 HC 基线先冻结。

最少对照包括 shared-only、单 adapter、固定混合、学习 Router；只有能力差异与可学习性已验证，才加 RECC。容量、训练时长和信息可获得性匹配。output-space residual 可作为简化接口的独立变量，但不预设它必然产生分工。

不默认重新做 latent 正交正则：E2 已说明它可能主要增加不可见方向。

### 8.3 路线 C：多步冻结专家库，优先于 CPM-MoE 开发

适用：当前 one-step 收益门不通过，且多步误差仍有空间。

先使用现有 CPM、AR 和不同历史视野的预测器，输出同一完整 horizon。对同样 val anchors/masks 检验 oracle 和可学习路由；新训练的预测器若有必要，计入试点预算。

冻结库通过后，才设计局部 CPM residual experts。第一版一个 Router 选择整段轨迹，避免每个 horizon 独立切换导致不连续。competence、checkpoint 选择、主验收统一到预设 H4–H8 轨迹指标；H1、free rollout 和 FC 为保护指标。

这属于原方案“第一版不做 CPM MoE”之后的新研究阶段，应独立记录架构与实验协议。

### 8.4 路线 D：结束复杂化，保留简单模型与有限诊断

适用：one-step 与多步冻结库均无可实现的实践收益。

保留已验证的 TFM/FiLM 或单 adapter，不再围绕近似平局调路由。整理负结果及边界，RECC 仅在有真实 competence 差异的候选集合上作诊断研究。

若改研究预测不确定性，另立分布输出和 proper-score/coverage/sharpness 协议；Router entropy 不能直接解释成预测不确定性。

### 8.5 暂不作为默认路线的工作

ROI/network 分区属于组成式输出：不同模块负责不同区域，原全脑单专家排名不再自动成立，必须重定义覆盖、组合和贡献评价。

真实干预预测需要 intervention-response 数据与验证。当前 future_control 接口、改变 HAMD 后输出变化，均不足以提供因果疗效证据。无真实数据时保留接口，不开展疗效预测训练。

## 9. S5：统计、稳定性与临床证据验收

### 9.1 预测收益与长程稳定性

通过有限试点后，采用至少 3 个配对训练 seed，每个 seed 的新旧方法共享同一 HC 权重和 split。已有 seed=2024 只算一份训练重复。

主报告包括绝对/相对收益、被试改善比例、配对区间、seed 间波动、H1/H4/H8/H16 和 GPU 成本。被试 bootstrap 不代表训练方差；多候选探索需要预设主比较和多重校正。

建议 G4 初始判据：主指标跨 seed 平均改善达到 1%，各 seed 改善方向一致；rollout H4/H8/H16 与 FC 不出现超过预设非劣界的恶化。非劣界可先建议相对 MAE 1%，最终根据 train/val 重复误差锁定。用区间评估边界，不能把 p>0.05 当作“没有恶化”。如果预算不足以形成足够窄的区间，报告不确定，不认定非劣。

当前 D 的 H16 +2.34% 将无法通过建议的稳定性门。

CPM 与 free rollout 分开报告；补充同 horizon 的 AR/trend/persistence。每个比较使用相同可用样本和 mask；跨 horizon 可另报告完整 H 子集，避免样本组成变化。

FC/频谱只使用足够轨迹长度。8个 TR 不直接当可靠 FC 估计；沿用既定至少32步评估并说明短轨迹的不稳定性。

### 9.2 病理条件的信息增益

在同一被试集合上比较 true HAMD、constant HAMD、被试级 shuffled HAMD 与重训 no-condition。constant 值与归一化统计仅来自 train；同一被试所有 anchors 使用同一置换值。

推理 shuffle 测试条件是否被使用；重训 no-condition/shuffled-condition 测试条件信息收益；两者分别解释。可获取样本充足时做 site 内置换，防止站点混杂。

先做 no-condition → HAMD；如果单独 HAMD 无信号但研究允许纳入其他已可用变量，再单独开展 Age/Sex 等条件消融。缺失处理/类别编码仅在 train 拟合，采用相同完整样本子集。人口学或站点收益不直接命名为病理发现。

### 9.3 临床表型与独立确认

将预测准确性、条件信息收益和临床表型关联分开验收。使用 HC normative deviation、network trajectory 或适配收益构建预设被试级表型，在训练/内层 CV 拟合后用独立被试/站点确认。

考虑可获得的 site、年龄、性别、头动和药物等混杂变量。HAMD 已作为输入时，分支输出与 HAMD 的相关可能由设计直接制造，需补条件无关特征或独立临床结局证据。

现有 test 已被多轮设计使用，新方案结果应标探索性；最终尽量使用未参与选择的外部站点或新锁定集合。没有此数据时如实限制结论，不用重新命名旧 test 代替独立验证。

预测门通过但临床门未通过，可以报告预测方法结果；不能继续主张已经证实病理机制或临床效用。

### 11.2 预算建议

| 工作 | 预算方式 | 约束 |
|---|---|---|
| S0/S1 | 工程与小型验证，无完整训练 | 先确认运行源码和契约 |
| S2 | 先小样本推理，再按吞吐估算全val费用 | 复用十份权重，不默认重训 |
| S3 | 冻结主干，只训练小型Router | 与试点共用预设费用上限 |
| S4 | 初始建议总筛选上限2 GPU·小时 | 是资源上限，不是预计足够训好的承诺 |
| S5 | 先估算3 seed配对对照的总费用 | 达到研究门后再确定长训练范围 |

S3/S4预算包含必要的新预测器训练和验证，不只计Router。若2 GPU·小时不足以完成有信息的试点，先调整可行范围或另定预算；短训阴性只说明该预算下未发现信号。

3 seed 的联合训练比较通常至少包含3次基线和3次新方法运行；已有与协议完全一致的基线可以复用，但不能只训练新方法三次后忽略基线随机性。Pair-RECC搜索不在首轮预算中。

本计划不自动授权长训练或数据覆盖；本轮也未启动它们。工程修复与结构/目标实验分开记录，便于审查和回滚。

修改聚焦、独立提交，保留旧 checkpoint 可读性；结构变更记录版本和重建字段，不修改旧权重。失败试点保留原始证据，停止后不顺带扩充专家数或调整其他模型参数。

## 12. 停止条件与完成定义

| 条件 | 必须采取的行动 |
|---|---|
| 源码/任务版本无法匹配 | 只完成可做的证据审计；暂停模型修复与复评 |
| G1正确性不通过 | 修契约/接线，不投入研究训练 |
| G2可行oracle空间不足 | 停止当前设置的预测型RECC与Pair-RECC |
| G2通过但G3无法实现 | 分析输入/噪声；不直接做λ/τ搜索 |
| one-step失败、多步冻结库成功 | 另立CPM专家阶段，统一轨迹监督与验收 |
| S4收益小于门槛或稳定性不通过 | 停止该试点，保留负结果 |
| 多seed不稳定 | 不宣称稳定方法收益 |
| 临床证据不足 | 限制病理/临床主张，不影响正确报告预测结果 |
| 所有低成本路线均未通过 | 保留简单模型，完成负结果与适用边界报告 |

计划执行完成不要求“RECC必须成功”。完成标准是：工程正确性得到验证；旧结果口径与污染范围澄清；收益空间和可学习性被检验；按验收门完成必要试点或停止；预测、临床与成本结论可复现且没有超出证据。
