## 3. 任务 2 协议核查结论（归档时执行）

1. **oracle 覆盖**：one-step——单专家（精确）、等权 pair（精确）、实际 Top-2 配比
   （=mixture 恒等）、全部 6 对的连续权重（MAE 分段线性凸 → 断点精确解，实际部署
   权重包含在候选集）；**未计算**全 4 专家任意连续权重 mixture（MAE 下非凸）——
   鉴于专家近乎同质（val 逐专家 MAE 全距 ≤1e-4），对结论无实质风险，但严格说
   pair+单专家不构成完整路由类上界，此处如实标注。多步——单预测器整段选择
   （对应 §8.3 v1 策略类）精确枚举 + 均匀库平均；预测器间连续混合未计算
   （标注为边界）。**未使用粗网格近似。**
2. **参照 = 最强可部署**：`best_deployable` 排除一切 look-ahead 策略
   （oracle/optimal-w 显式排除并标注）；固定策略用被试级 LOSO cross-fit；
   所有策略共用同一批收集的 preds/target/mask 与同一被试内→跨被试聚合。
   **发现与修正**：多步门槛原以 Huber competence 判定；归档复核以 MAE 窗口
   重算仍通过（2.58%/5.18%），G2-multi 结论对指标选择稳健（数字见 §2.6 表）。
3. **被试分离**（代码级复核）：Router 训练仅用 `feats[is_calib]`
   （`analysis/train_frozen_router.py` / `analysis/reeval_multistep_library.py`）；
   被试级 50/50 划分 `RandomState(2024)`；固定专家仅在校准半区选择；
   归一化为逐样本 LayerNorm（无跨被试拟合统计）；超参固定、无验证集调参。
   同一被试的 anchor 不跨集合。
4. **四设置分列报告**：见 §2.6 表（oracle 收益 / Router 收益 / 固定基线 / n=3825）。
5. **test 探索性**：已标注，未用于调整门槛。
