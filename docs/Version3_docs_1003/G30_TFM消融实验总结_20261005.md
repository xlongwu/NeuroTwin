# G30_TFM 消融实验总结（2026-10-05）

## 1. 概述

- **目的**：对 NeuroTwin-TFM 主干（TimesFM-3 风格，方案 §30 V1）做组件级消融，确定各设计组件对 next-timepoint 预测任务的贡献，并据此确定主干最优配置。
- **执行**：2026-10-03 至 2026-10-05，`experiments.run_experiments` 框架批量执行，4 个 GPU runner 并行调度。
- **统一设置**：seed=2024（单种子）；git commit `1f59558`；数据 MDD 静息态 AAL116（test 225 被试 / 3825 任务）；任务口径 next_timepoint（context ≤64 TR → 预测 t+1，prediction_target=delta）；评估协议含 persistence/trend/AR(1) 基线、free rollout（H1–H16）、FC 边级指标、shuffled-HAMD 负对照。
- **状态**：9/9 变体全部 success，无失败记录。

## 5. 结论

以下区分**事实**（数据直接支持）、**推断**（由事实推出的解释）、**待验证**（需后续实验确认）。

### 事实

1. **patch 长度是唯一有实质影响的维度，且单调**：p=1 比 baseline 差 53%，p=8 好 11%，在 t+1、全部 rollout 步长、FC、方向准确率上方向一致。三变体参数量几乎相同（≈6.03M），可排除容量解释。
2. **7 个"移除组件"型消融全部 ≤ baseline**（−0.04% ~ −2.0%，无一变差；patch1 是改变 token 粒度而非移除组件，不在此列）。
3. **HAMD 条件通路未被利用**（双证据）：no_cond 与 baseline 差 −0.04%（≈0）；置换评分负对照 Δ≈0。
4. **SC 组件是唯一点预测与 FC 结论相反的消融**：去掉结构先验或双随机化后点预测略好（−1.0% / −0.9%），但 FC edge PCC 从 0.479 降至 0.417–0.419（−13%）。
5. **长程自回归误差累积是共性瓶颈**：所有变体 rollout MAE 从 t+1 ≈0.075 增至 t+16 ≈0.9；baseline 在 H16 被 AR(1) 递推反超，仅 patch8 保持优势。
6. PCC_spatial 已饱和（≈0.994，被试间 std 0.002），对消融不敏感。

### 推断（解释，非定论）

- 时间 token 的聚合粒度（等效时间感受野）是当前架构的主要杠杆；patch8 的长程优势或源于更强的时序压缩带来的稳定性。
- CPM 辅助分支对主任务无正迁移（去掉后 rollout/FC 亦全面略好）。
- SC 结构先验的价值体现于生成序列的功能连接保真度，而非点预测精度；若研究主张涉及 FC 质量，这是保留该组件的理由。
- "移除组件全部 ≤ baseline" 的模式或说明组件存在轻微干扰/过参数化，或说明单种子下简单模型更易训好——两种解释当前数据无法区分。

### 待验证

- 所有结论基于 **seed=2024 单种子**；<2% 的组间差异（no_cpm / sc_* / no_delta_a / gamma_decay / no_cond 之间的排序）需多 seed 确认后方可作为论文结论。
- p=8 未必是上界（p=16 未测试）；CPM γ=0.9 单一取值。
- "移除全部无贡献组件"的组合配置（p=8 + 无 CPM + 无 SC + 无 HAMD）未训练过，各消融的微小优势不可假设可叠加。
- 结论限于单一数据集（MDD 静息态 AAL116）与单一任务（next-timepoint delta）。
