# NeuroTwin 神经微分方程调研与优化改进方案

> 调研日期：2026-09-22  
> 范围：`models/common.py` 的 `GraphODE` / `GraphODEDDI`，及其在 HC 预训练、MDD 微调中的使用。  
> 目标：让“微分方程”部分具有可检验的数值与建模含义，同时在 AAL116、历史 6 窗、每窗 30 点、MDD 小样本的约束下控制风险。

## 结论先行

当前 `GraphODEDDI` 更准确地说是**共享参数的图时空 RK2 深度块**，而不是已经与 BOLD 采样时钟绑定、并经过求解器收敛验证的连续时间脑动力学模型。它仍然可能是有效预测器，但在完成步数/稳定性实验之前，不应把性能提升归因于“连续生理时间建模”。

最值得优先投入的不是立刻换成 Neural SDE 或复杂神经质量模型，而是：

1. **P0：确认或纠正积分语义**——完成 `ode_steps` 收敛、轨迹稳定性与计算代价基线；若保留可学习步长，应使 RK2 stage 与该步长一致。
2. **P1：把 SC 从硬可达性约束升级为受控的结构项**——采用“可解释图拉普拉斯/扩散项 + 小型神经残差”的 UDE，而非完全黑盒向量场；并使用稳定性正则。
3. **P2：只有在数据确有不等间隔、缺失或不同 TR 时才引入 Neural CDE**。这是把“历史观测持续驱动状态”做成真正连续时间模型的正确路线。
4. **P3：拥有 tract length、传导速度假设和 HRF/神经质量层时，再研究延迟微分方程或随机微分方程**。它们有明确的脑网络对应物，但目前数据接口不支持可信验证。

## 1. 当前实现：已确认事实

| 项目 | 代码事实 | 含义 |
|---|---|---|
| 状态 | `h` 的形状为 `[B, ROI=F, history-window=W, within-window=S]`；当前常用为 `[B,116,6,30]` | 一次积分更新的是整段历史特征张量，不是单一时刻的 ROI 状态 `x(t)`。 |
| 向量场 | 图注意力（SC hard mask + `log1p(SC)` bias）、时间深度卷积、跨 window attention、FFN 的门控和 | 有图时空归纳偏置；但四条支路均以同一历史张量为输入。 |
| 时间变量 | `GraphODE.forward(t, ...)` 第一行即 `del t`；每个 RK2 调用传入 `0` | 当前是自治向量场；自治本身并不错误，但 `t` 不承载 TR、窗口时间或不等间隔。 |
| 积分 | `dt=1/ode_steps`，每步计算 `k1=f(h)`、`k2=f(h+dt*k1)`，再累加 | 固定 6 步（默认），没有容差控制、NFE 记录、步数收敛或长轨迹稳定性证据。 |
| 可学习缩放 | 更新量被 `softplus(step_scale_raw)` 乘；但 `k2` 的 stage 位移仍使用未缩放的 `dt` | 当缩放不等于 1 时，这不是严格对应某一常规 Heun/RK2 Butcher tableau 的更新；应视为门控残差，或修正为一致的有效步长。 |
| 块级融合 | 每个 ODE block 外还有零初始化的残差尺度 `x ← x + sigmoid(block_scale)(evolved-x)` | 初始约为 0.5，而不是严格 identity；ODE 的实际贡献需要以消融和轨迹统计确认。 |
| 训练监督 | PCC、MAE、一阶差分、标准差；没有导数、稳定性、FC/dFC 或求解误差监督 | 当前目标保证波形统计，不保证多步积分可靠，亦不保证派生 FC 拓扑正确。 |

相关位置：`models/common.py:281`（`GraphODE`）、`models/common.py:403`（`GraphODEDDI`）、`models/neurotwin.py:322`（ODE block 构建）、`models/neurotwin.py:382`（编码路径）。

### 两个需要避免的误判

- **`t` 被忽略不自动等于 bug。** 自治 ODE `dh/dτ=f(h)` 合法；问题在于本项目将积分轴命名/解释为脑时间，但状态、时间戳与预测窗均未在该轴上定义。
- **更多 RK2 step 不自动更好。** 对共享权重深度块，`ode_steps` 还会改变有效网络深度、正则化和计算量。只有误差随 step 收敛、且轨迹统计稳定时，才能支持数值积分的解释。

## 2. 可借鉴的微分方程路线

| 路线与代表工作 | 它解决的核心问题 | 对 NeuroTwin 的适配结论 |
|---|---|---|
| [Neural ODE](https://proceedings.neurips.cc/paper/2018/hash/69386f6bb1dfed68692a24c8686939b9-Abstract.html), Chen et al., NeurIPS 2018 | 用连续深度向量场和 ODE solver 代替离散残差层，并显式权衡精度与计算 | 是当前模块的概念起点。应借鉴其“solver/容差/计算量可验证”的纪律，而不是只保留 RK2 外形。 |
| [On Numerical Integration in Neural ODEs](https://proceedings.mlr.press/v162/zhu22f.html), Zhu et al., ICML 2022 | 训练和推理中的数值离散会改变实际学到的动力学 | 强烈相关。必须做步数、有效步长、训练/推理 solver 一致性和耗时报告。 |
| [Stable Neural Flows](https://arxiv.org/abs/2003.08063), Massaroli et al. | 以能量/稳定性约束减少轨迹对扰动的放大 | 适合长预测和小样本。先使用轻量 Jacobian/增量稳定性正则，不建议首版直接替换为复杂能量网络。 |
| [Latent ODEs](https://arxiv.org/abs/1907.03907), Rubanova et al., NeurIPS 2019 | 将不规则采样观测编码到连续隐状态后解码任意时刻 | 适用于未来拥有真实时间戳、变长扫描或缺失帧的场景；当前整齐的 6×30 输入不足以证明其优势。 |
| [Neural CDE](https://papers.neurips.cc/paper/2020/hash/4a5876b450b45371f6cfe5047ac8cd45-Abstract.html), Kidger et al., NeurIPS 2020 | 以连续插值观测路径驱动隐状态，处理不规则/部分观测时序 | 比“把时间 embedding 加给当前 GraphODE”更符合历史 BOLD 持续驱动状态的需求；列为 P2。 |
| [Neural Delay Differential Equations](https://arxiv.org/abs/2102.10801), Zhu et al., ICLR 2021 | 用 `x(t-τ)` 表达非 Markov 记忆和传播延迟 | 脑网络很契合，但需要可验证的 delay 来源；不能从 30 点 BOLD 窗口直接臆造生理延迟。 |
| [Universal Differential Equations](https://arxiv.org/abs/2001.04385), Rackauckas et al. | 将已知机制项和可学习未知项组合，而非全黑盒拟合 | 最适合 SC 先验：显式扩散/拉普拉斯项保留结构含义，神经网络只拟合剩余动力学。 |
| [UDE for Neuroscience](https://arxiv.org/abs/2403.14510), ElGazzar & van Gerven | 将机制、观测与神经网络结合为神经科学建模语言 | 支持将本项目定位为“机制约束的预测模型”；前提是清楚区分可检验先验与未经识别的生理参数。 |
| [The Virtual Brain](https://docs.thevirtualbrain.org/) / 全脑神经质量模型 | 区域动力学通过 SC、传导延迟和局部神经质量模型耦合，可模拟 BOLD | 提供延迟、噪声、SC 耦合的生物学动机；并不意味着应直接复刻其参数量和仿真链路。 |

全脑模型常写成 `d x_i/dt = F_i(x_i) + Σ_j K_ij G(x_j(t-d_ij)) + I_i(t)`；SC 权重、延迟和局部区域动力学各自具有不同角色。该分解比把 SC 只作为 attention hard mask 更利于解释，但要避免把 BOLD 时间分辨率之外的量误认为可由数据识别。

## 3. 建议方案与优先级

### P0 — 先验证“ODE 是否带来可重复收益”

不改模型结构，先形成以下表格。所有组使用相同 subject-level split、训练预算、种子和确定性验证路由。

| 对照 | 必测项 | 决策规则 |
|---|---|---|
| `ode_steps={1,3,6,12}` | 波形 PCC/MAE、FC edge-PCC/MAE、每 epoch 时间、显存、每积分步 `||k1||`/`||k2||`/`||Δh||`、NaN/梯度裁剪次数 | 若 1 step 在置信区间内不差于 6/12 step，后续将其表述为共享图残差块，并把研究资源转给预测头或图先验。 |
| `step_scale=1` 固定 vs 可学习 | 最终 `step_scale` 分布、性能、步数敏感性 | 若可学习缩放趋近 0 或性能不稳，删除它而保留外层 block residual scale。 |
| 当前 RK2 vs 一致有效步长 RK2 | 同上，并报告 solver sensitivity | 仅当一致版本不损害性能且减小步数敏感性时，将其作为默认。 |
| train step 与 eval step 一致/不一致 | 性能差与轨迹差 | 差异明显时，禁止改变推理 step 数或宣称 solver 无关。 |

**一致有效步长 RK2（建议候选实现）**：令 `Δτ = softplus(step_scale_raw) / ode_steps`；使用

```text
k1 = f(τ, h)
k2 = f(τ + Δτ, h + Δτ·k1)
h  = h + Δτ·(k1 + k2)/2
```

这样才使所有 RK2 stage 使用同一个有效步长。若不希望 `step_scale` 代表物理时间，最简洁的选择是固定 `Δτ=1/ode_steps`，把可学习的增益留在块级残差处。

### P1-A — 稳定的 SC-UDE：显式图项 + 小型神经残差

这是优先推荐的结构改造。将当前所有分支相加的黑盒导数改为：

```text
dh/dτ =  - κ(τ,h) · L(A(τ))h          # 显式、耗散的图耦合项
        + f_local(h, τ)                # ROI 内局部时间动力学
        + r_θ(h, SC, τ)                # 小型、受限的神经残差

A(τ) = λ(τ,h)·normalize(SC) + [1-λ(τ,h)]·A_func(h)
```

- `κ=softplus(κ_raw)`，`λ=sigmoid(·)`，保证图扩散强度非负、SC 和功能邻接的混合可审计。
- `A_func` 从 pooled ROI latent 构造低秩 `UVᵀ`（rank 8 或 16），对称化、去对角并用 row-softmax/归一化；不使用 116² 自由边参数。
- 仅让 `r_θ` 承担不能由局部项和图项解释的残差。先保留现有 temporal branch，缩小/移除重复 FFN 和全量图 attention 后再比较，避免机制项与黑盒支路互相抵消。
- 训练初值设为接近当前稳定基线：`κ` 小、`λ` 偏向 SC、`r_θ` 或新分支门控零初始化。HC 预训练后，MDD 阶段优先更新 `λ/A_func/r_θ` 的 adapter，而非全量解冻主干。

**稳定性约束（从轻到重）**：

1. `L_vel=mean(||f(h)||²)` 和 `L_curv=mean(||f(h+ε)-f(h)||²/ε²)`，只作为防止无意义高速/剧烈向量场的弱正则；
2. 以同一输入加小扰动，约束 `||Φ(h+δ)-Φ(h)|| / ||δ||` 不超过阈值，其中 `Φ` 是整个 ODE block；
3. 仅在前两项有效后，估计 Jacobian 对数范数或施加谱归一化。

不要把“负拉普拉斯项”当作无风险稳定化：它也会过平滑 ROI 差异。必须报告 ROI 方差、FC 误差及 `κ/λ` 分布，而不只报 PCC。

### P1-B — 让积分轴可解释，但不伪造真实时间

如果所有样本等间隔，先将当前积分变量明确命名为**depth time** `τ∈[0,1]`，并在论文中不等同于 BOLD 秒数。可选地把 Fourier time embedding `e(τ)` 输入 `f_local`、`λ` 和 `r_θ`，得到非自治深度流：

```text
dh/dτ = f_θ(h, e(τ), SC).
```

它可提高不同深度阶段的表达能力，但不构成连续生理时间建模。只有数据管线提供每窗/每帧真实 timestamp 或 `Δt` 时，才将其替换为真实时间坐标，并在训练、验证和干预路径中统一传递。

### P2 — Neural CDE 编码器：将连续观测历史与深度积分区分开

当存在不规则采样、删帧、不同扫描协议或需要在任意未来时刻预测时，建议以 Neural CDE 替换编码端的 `GraphODEDDI`，而非继续在完整 `[F,W,S]` 张量上做 depth integration：

```text
observations [B, F, T] + timestamps/mask
      → 每 ROI 插值控制路径 X(t)（另含 time/mask 通道）
      → dz(t) = f_θ(z(t), SC, t) dX(t) + g_θ(z(t), SC, t) dt
      → z(t_last) + future-time queries → future BOLD
```

- `X(t)` 使用训练集内定义的线性或 cubic spline；时间和缺失掩码必须成为控制通道，不能仅做零填充。
- 建议状态为 `[B,F,d]` 或 module-level state，而不是将全部历史再次塞进状态；SC-UDE 的低秩图项可复用在 `f_θ/g_θ` 中。
- 首个实验只做 HC 单步预测，并对“规则全数据 / 人为不规则 / 缺失帧”三种设置进行同预算比较。若规则全数据无收益，这是合理结果，不应强推替换。

### P3-A — 延迟 UDE / 神经质量先验：有数据再做

若具备每个被试（或可靠群体）的 tract length 矩阵、TR、传导速度先验和明确 BOLD 观测模型，可测试

```text
ds_i/dt = f_local(s_i) + c·Σ_j SC_ij·g(s_j(t-d_ij)) + r_θ(s, SC),
     d_ij = length_ij / velocity.
```

推荐先学习很少的全局参数（全局耦合 `c`、少量 module delay、或低维 delay basis），不学习每条边独立延迟。由于 BOLD 是血流动力学的慢观测，最好显式说明该状态是 latent neural state，观测头才映射为 BOLD；否则 `d_ij` 很可能不可辨识。

### P3-B — 不确定性：先做预测区间，再考虑 Neural SDE

MDD 小样本和个体差异确实有随机性动机，但神经 SDE 会引入采样方差、求解器选择和更多参数。第一阶段应采用 ensemble/MC dropout 或异方差输出，报告 calibration、coverage 和 CRPS/NLL；只有不确定性评估稳定且有足够重复测量时，才比较

```text
dh = f_θ(h,t)dt + σ_θ(h,t)dW_t.
```

这一路线不应列为当前主创新。

## 4. 实验设计：怎样判定“方程改进”而非偶然增参

### 必备指标

| 维度 | 指标与统计单位 |
|---|---|
| 波形 | 每样本 ROI PCC、MAE、RMSE、temporal-difference；先按被试聚合，再做 paired bootstrap CI。 |
| 网络 | 预测/真实窗的 Pearson FC 上三角 edge-PCC、Fisher-z FC MAE、网络内/网络间误差；FC loss 仅使用低权重辅助项（30 点窗估计本身高方差）。 |
| 数值 | NFE、wall time、峰值显存、`||f||`、`||Δh||`、梯度范数、NaN/裁剪频率、step doubling 差 `||Φ_N(h)-Φ_2N(h)||`。 |
| 稳定 | 对输入加入固定幅度噪声的输出放大率；预测窗增加到 1/2/3 时的误差曲线；不同 seed 的均值±CI。 |
| 机制 | `κ`、`λ`、功能邻接 rank/熵、SC 与 `A_func` 的相似度；只报告为模型敏感性，不直接称为生物标志物。 |

### 分阶段最小矩阵

| 阶段 | 对照组 | 通过门槛 | 失败后的动作 |
|---|---|---|---|
| 0：语义与数值 | current、固定步长 RK2、一致有效步长 RK2 × `N={1,3,6,12}` | 不降低主要指标，且 step doubling 差/训练不稳定性改善 | 退回最简 1-step 图残差块，停止“ODE”叙述。 |
| 1：SC-UDE | fixed-SC、adaptive-only、SC+`A_func`、SC-UDE+稳定正则 | 至少在 HC 和 MDD 的被试级 CI 上一致改善；没有明显 FC 退化 | 保留 SC soft prior，不加入复杂神经残差。 |
| 2：真实连续时间 | current encoder、CDE encoder；规则/不规则/缺失三设置 | 仅在含时间不规则性场景中显示稳健收益 | 保持规则序列模型，不把 CDE 纳入主线。 |
| 3：机制扩展 | no-delay、global-delay、module-delay UDE | 预测与参数稳定性均优于无 delay，且 delay 与数据元信息一致 | 放弃 delay，避免不可辨识的生理解释。 |

所有模型应参数量匹配或报告参数/计算量；HC→MDD 的比较应统一冻结策略；验证和最终测试必须使用确定性 MoE 路由。每个候选至少 5 个种子，并只在独立 test 上做一次最终选择性报告。

## 5. 实施顺序与文件影响（本次未改代码）

1. **测量先行（低风险）**：在 `models/common.py` 给 `GraphODEDDI` 返回可选诊断（每步 `k1/k2/delta` norm、有效步长）；在 `main.py`/分析脚本记录聚合指标和耗时。此步不改变模型结构。
2. **修正并参数化 RK2（低风险）**：新增 `ode_solver_mode={current,consistent_rk2}`、`ode_steps` 消融；默认保持 current，直到复现实验证明一致版本可替换。相应更新 `main.py` CLI、训练脚本和 README。
3. **SC-UDE（中风险）**：在 `models/common.py` 新增独立 `StructuredGraphUDEBlock`，不覆盖 `GraphODEDDI`；以 CLI 选择，两者共享下游 ForecastHead。新增 FC 指标/低权重 loss 前先固定其计算定义。
4. **CDE（中高风险）**：先扩展 `utils/dataloader.py`，显式输出 timestamps 和 masks；没有这些接口，不实现 CDE。
5. **延迟/神经质量（高风险）**：在独立实验目录和配置中实现，不和主模型同一轮同时改动，防止无法归因。

## 6. 明确不建议现在做的事情

- 不在没有时间戳、TR 和不规则采样实验的情况下，把 `torchdiffeq` 的自适应 solver 作为“连续时间升级”。这只会改变计算预算和复现实验难度。
- 不把每个 SC 边的 delay、扩散系数或独立动力学参数都设为可学习；116 个 ROI 下会造成严重不可辨识和小样本过拟合。
- 不同时引入动态邻接、CDE、DDE、SDE、MoE 改造和新预测头；任何收益都无法归因。
- 不因采用 UDE/神经质量术语就声称生物物理可解释性。可解释性至少需要参数稳定性、基线对照、被试级统计和与已知元信息的一致性检验。
