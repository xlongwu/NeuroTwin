# 个体化动力学模型修改前后对比

评估日期：2026-11-02。对比对象为修改前正式 H1–8 权重与新方案 150 轮预算下的最佳权重。

**结论：本次新模型的预测表现明显退化，目前不应替代修改前模型。** HC 与 MDD 的单步、多步误差均明显增加，功能连接和频域指标也下降；退化在 HC 训练阶段已经出现，并非仅发生在病理微调阶段。

## 1. 对比对象和协议核验

| 项目 | 修改前 | 修改后 |
|---|---|---|
| HC 权重 | `checkpoints/1031/neurotwin_pretrain/base_best.pt` | `checkpoints/个体化动力学150轮_20261102_152657/neurotwin_B2_pretrain/base_best.pt` |
| MDD 权重 | `checkpoints/1031/neurotwin_finetune/finetuned_best.pt` | `checkpoints/个体化动力学150轮_20261102_152657/neurotwin_B3_finetune/finetuned_best.pt` |
| HC 最佳权重轮次 | 30 | 41（第 53 轮早停） |
| MDD 最佳权重轮次 | 19（最大 30 轮） | 150 |
| HC 条件 | hc3/demo | hc3/demo |
| MDD 条件 | mdd8/cat：包含症状、病程等字段 | hc3/demo：仅人口学字段 |
| MDD 训练策略 | 前期条件适配，随后解冻共享模型 | 冻结健康模型和 IDG，仅训练 PDD |

旧权重虽然移动到 `checkpoints/1031/`，SHA256 与 `configs/neurotwin.json` 和历史评估记录中的正式基线完全一致。新旧 HC、MDD 的被试划分哈希分别一致。

评估均使用 Raw BOLD 的最早 32 TR 校准、K64 可见历史、每被试 8 个固定锚点、固定锚点 H1–8 外推，无未来真值反馈。HC 测试集 222 人、1,776 个锚点；MDD 测试集 225 人、1,800 个锚点。逐任务的被试、历史长度和 cutoff 完全匹配，H1–8 持久性基线最大数值差为 0。

先在每名被试内对锚点平均，再跨被试等权。下列多步指标来自 **Graph-ODE**，不混入未参与本轮主监督的 CPM 预测头，也不混入滚动单步结果。

## 2. 测试集主要结果

| 指标 | HC 修改前 | HC 修改后 | MDD 修改前 | MDD 修改后 |
|---|---:|---:|---:|---:|
| 单步 MAE，越低越好 | 0.0906 | 0.6035 | 0.0920 | 0.5949 |
| 单步 RMSE，越低越好 | 0.1156 | 0.7549 | 0.1174 | 0.7487 |
| 单步空间 PCC，越高越好 | 0.9938 | 0.7785 | 0.9935 | 0.7734 |
| H1–8 MAE，越低越好 | 0.5344 | 1.2458 | 0.5321 | 1.2321 |
| H8 MAE，越低越好 | 0.8110 | 1.4275 | 0.8018 | 1.4154 |
| H8 空间 PCC，越高越好 | 0.4286 | -0.1867 | 0.4359 | -0.1782 |
| H1–8 FC MSE，越低越好 | 0.2446 | 0.2715 | 0.2468 | 0.2682 |
| H1–8 FC PCC，越高越好 | 0.6034 | 0.4477 | 0.6012 | 0.4521 |
| H1–8 频域 L1，越低越好 | 0.3624 | 0.9227 | 0.3589 | 0.9168 |

HC 单步 MAE 增加 565.8%，H1–8 MAE 增加 133.1%。MDD 单步 MAE 增加 546.8%，H1–8 MAE 增加 131.6%，H8 MAE 增加 76.5%。这些是同协议下的结果差异，不是把训练集与测试集、不同时间范围或不同预测头混合得到的变化。

## 3. 被试配对与不确定性

222 名 HC 和 225 名 MDD 测试被试，在单步 MAE、H1–8 MAE、H8 MAE 上均未出现改善。退化并非少数异常被试抬高均值。

| 队列与指标 | 新减旧的均值差 | 差值的 95% 区间 |
|---|---:|---:|
| HC 单步 MAE | +0.5129 | [0.4989, 0.5272] |
| HC H1–8 MAE | +0.7115 | [0.6921, 0.7305] |
| MDD 单步 MAE | +0.5029 | [0.4918, 0.5144] |
| MDD H1–8 MAE | +0.7000 | [0.6808, 0.7195] |

区间采用被试级配对 bootstrap，重采样 5,000 次，固定随机种子 2024。它反映这批测试被试的抽样变异，不包含重新训练不同随机种子的变异，也不是单个模块的因果效应区间。

## 4. 新模型接近持久性预测

MDD 测试集的单步持久性 MAE 为 0.5956，新模型为 0.5949，改善仅约 0.11%；线性趋势基线为 0.5363，AR(1) 为 0.5640，均优于新模型。

MDD H1–8 持久性 MAE 为 1.2457。旧模型的 MAE 为 0.5321，相对持久性改善 57.29%；新模型为 1.2321，相对持久性仅改善 1.10%。

在 H8，预测相邻帧变化幅度与真实变化幅度的比值，从旧模型的 0.7405 降为新模型的 0.00114，即新模型该步变化仅为真实变化的约 0.114%。结合逐时距曲线，新模型多步轨迹表现出明显趋平，接近持续重复最后一次观测值。该数值是相邻帧差分幅度比，不是跨 ROI 方差比。

## 5. 延长预算后的变化

| MDD 测试指标 | 新方案原 30 轮运行 | 新方案 150 轮预算运行 |
|---|---:|---:|
| 单步 MAE | 0.5959 | 0.5949 |
| H1–8 MAE | 1.2440 | 1.2321 |
| H8 MAE | 1.4295 | 1.4154 |
| 单步空间 PCC | 0.7759 | 0.7734 |

延长预算后，新方案 H1–8 MAE 约改善 0.96%，单步空间 PCC 略降，尚未恢复修改前模型的预测能力。两次运行的学习率调度预算及选中轮次也不同，这张表是两次实际运行的结果对比，不是相同学习率轨迹下的单纯多训练若干轮实验。

## 6. 结论边界与下一步

可以确认：当前两套实际权重的预测表现存在稳定而明显的差距，旧模型更好；HC 阶段已退化，冻结该健康基础后的 PDD 微调未恢复旧模型表现。

不能据此确认：IDG、SDRL 或 PDD 的哪一项单独造成退化。新旧结构、辅助损失、训练预算、MDD 条件字段和冻结策略同时发生变化，尚无逐模块受控消融。此次结果也没有验证个体身份稳定性、疾病辅助分类或临床关联，因此不把预测退化扩展为这些任务上的结论。

建议保留修改前模型作为预测基线，优先定位 HC 阶段的学习退化，再做新增模块和损失的逐项对照。仅继续延长训练预算，已有结果不足以支持其能解决当前问题。本次没有调整模型或重新训练。
