# 全面模型分析指南

## 概述

[analysis/run_comprehensive.py](analysis/run_comprehensive.py) 是一个全面的模型分析工具（CLI 入口，核心逻辑位于 `analysis/analyzer.py` / `metrics.py` / `visualizer.py` / `checkpoint.py`），用于深入分析 NeuroTwin 模型的性能、可解释性和行为特征。

## 功能特性

### 1. 评估指标分析

#### 基础指标
- **MAE** (Mean Absolute Error): 平均绝对误差
- **MSE** (Mean Squared Error): 均方误差
- **RMSE** (Root Mean Squared Error): 均方根误差
- **PCC** (Pearson Correlation Coefficient): 皮尔逊相关系数
- **R²** (Coefficient of Determination): 决定系数

#### 高级指标
- **SMAPE**: 对称平均绝对百分比误差
- **MASE**: 平均绝对比例误差
- **误差百分位数**: 50th, 90th, 95th, 99th
- **误差偏度和峰度**: 分析误差分布形态
- **ROI 级别指标**: 每个 ROI 的 MAE、MSE、PCC
- **时间维度指标**: 窗口级和序列级 MAE

### 2. 可视化图表

#### 基础可视化
- `001_prediction_scatter.png`: 预测 vs 真实值散点图 + 残差图
- `002_error_distribution.png`: 误差分布直方图、Q-Q 图、箱线图
- `003_sample_pcc_distribution.png`: 样本 PCC 分布分析

#### ROI 与时间分析
- `004_roi_heatmap.png`: ROI 级别 MAE、PCC、方差热力图
- `005_temporal_metrics.png`: 窗口级和序列级 MAE、时间方差对比

#### 模型组件分析
- `006_moe_gate_analysis.png`: MoE 专家门控权重分析
- 专家-HAMD 分布分析图（`plot_expert_hamd_distribution`）：各专家样本的 HAMD 分层分布

#### 相关性分析
- 病理分数与性能相关性图（`plot_pathology_correlation`）

#### 特征重要性与显著脑区
- ROI 置换重要性分析图（`plot_feature_importance`）
- FDR 校正显著脑区统计与玻璃脑图（`plot_significant_brain_regions`，输出 `glass_brain_<network>.png`）

#### 时间序列预测
- 具体样本和 ROI 的预测可视化（`plot_temporal_prediction`）

#### 综合仪表板
- 8 宫格综合仪表板（`plot_comprehensive_dashboard`）

### 3. 可解释性分析

#### MoE 统计
- 专家门控权重分布（`aux_info` 中 `gates/soft_gates`）
- 专家-HAMD 分层分析（`--expert_assignment_method` 支持 `top1`/`threshold`）
- 专家使用频率与负载统计

#### 特征重要性
- 基于置换的重要性分析（支持 `--feature_importance_permutations` 多次置换）
- Top-K 重要 ROI 排序
- FDR 校正（`fdr_alpha=0.001`）后的显著脑区网络分组统计

#### 虚拟干预（模型内置接口）
工具本身不再包含干预实验流程；如需干预分析，使用模型内置的
`NeuroTwin.virtual_intervention`（见 [models/neurotwin.py](models/neurotwin.py)），
支持 `excitatory`（兴奋性）、`inhibitory`（抑制性）、`variance_boost`（方差增强）、
`variance_suppress`（方差抑制）四种类型，通过目标 ROI 与强度控制。

## 使用方法

### 基本用法

```bash
python analysis/run_comprehensive.py \
    --finetuned_weight "/path/to/your/model.pt" \
    --data_root "/path/to/data" \
    --output_dir "./analysis_results"
```

### 完整参数

```bash
python analysis/run_comprehensive.py \
    --finetuned_weight "/path/to/model.pt" \
    --data_root "/path/to/data" \
    --output_dir "./analysis_results" \
    --run_name "my_analysis" \
    --batch_size 16 \
    --num_workers 4 \
    --generate_visualizations True \
    --compute_feature_importance True \
    --feature_importance_samples 100 \
    --feature_importance_permutations 200 \
    --expert_assignment_method top1 \
    --save_arrays True
```


## 参数说明

### 必需参数
- `--finetuned_weight`: 微调后的模型权重路径

### 可选参数

#### 路径参数
- `--data_root`: 数据根目录（默认 `/data3/Digital_Brain/AMD/data`）
- `--output_dir`: 输出目录
- `--run_name`: 运行名称（默认 `comprehensive_analysis`）
- `--clinical_file`: 临床数据文件（HAMD 评分表）
- `--hamd_normalized_file` / `--hamd_original_file`: HAMD 归一化/原始量表文件（用于样本匹配与可视化）

#### 数据参数
- `--num_rois`: ROI 数量（默认 116）
- `--seq_len`: 序列长度（默认 30）
- `--in_window`: 输入窗口数（默认 6）
- `--pred_window`: 预测窗口数（默认 1）
- `--total_windows`: 总窗口数（默认 9）

#### 分析参数
- `--generate_visualizations`: 生成可视化图表（默认 True）
- `--compute_feature_importance`: 计算特征重要性（默认 True）
- `--feature_importance_samples`: 特征重要性样本数（默认 50）
- `--feature_importance_permutations`: 置换次数（默认 200）
- `--expert_assignment_method`: 样本-专家分配方式（`top1` / `threshold`，默认 `top1`）
- `--save_arrays`: 保存预测数组（默认 True）
- `--strict_load`: 严格加载 checkpoint（默认 False，允许键名兼容）
- `--device`: 计算设备（`auto`/`cuda`/`cpu`）
- `--batch_size` / `--num_workers` 等 DataLoader 参数

## 分析结果解读

### 关键指标

| 指标 | 说明 | 理想值 |
|------|------|--------|
| MAE | 平均绝对误差 | 越小越好 |
| RMSE | 均方根误差 | 越小越好 |
| PCC | 皮尔逊相关系数 | 接近 1 或 -1 |
| R² | 决定系数 | 接近 1 |
| SMAPE | 对称平均绝对百分比误差 | 越小越好 |

### MoE 门控解读

- `gates`: 硬门控权重（top-k 位置置入对应专家概率）
- `soft_gates`: 路由器完整 softmax 概率
- `importance`: 各专家平均分配概率（soft）
- `load`: 各专家实际被路由比例（hard top-k）
- `router_entropy`: 路由熵，过低意味着路由趋于确定性/塌缩

理想状态是多专家均有参与（load 分布不过度集中）且路由熵不过低。

### 特征重要性解读

- 置换重要性：扰动某 ROI 输入后性能下降越多，该 ROI 越重要
- 显著脑区：经 FDR 校正后的 ROI 按脑网络（DMN/FPN/VAN/LN/VN 等）分组汇总
- 配套脚本 [analysis/visualize_roi_importance.py](analysis/visualize_roi_importance.py) 与 [analysis/visualize_sig_region.py](analysis/visualize_sig_region.py) 提供论文级可视化

## 注意事项

1. **显存要求**: 特征重要性分析需要较多显存，如遇 OOM 可减少 `--feature_importance_samples` 或置换次数
2. **时间消耗**: 多次置换的特征重要性分析耗时较长，可按需调整
3. **依赖项**: 确保已安装 matplotlib、seaborn、scipy、nilearn（玻璃脑可视化需要）等依赖

## 故障排除

### 问题: 找不到模块
**解决**: 确保在项目根目录（NeuroTwin/）下运行，或设置 PYTHONPATH

### 问题: CUDA 内存不足
**解决**:
- 减小 `--batch_size`
- 减少 `--feature_importance_samples` 与 `--feature_importance_permutations`
- 使用 CPU: `--device cpu`

### 问题: 可视化失败
**解决**:
- 安装依赖: `pip install matplotlib seaborn scipy nilearn`
- 设置 `--generate_visualizations False` 跳过可视化
