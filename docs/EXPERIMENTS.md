# 实验结论与最终保留结果

本轮实验已于 2026-10-25 收尾。此后按用户要求精简项目，仅保留最终运行代码、
最优 H32 权重、必要的 HC/H8 契约权重及最终数值证据，不自动继续研究链。
清理不改变权重内容或重算实验结果；历史完整任务目录、失败日志和诊断大数组已移除。

## 当前保留的模型

- **最优长程模型**：S2 历史记忆 + Graph-ODE + CPM，完整 H32 监督，原分组 E2 目标。
  权重为 `checkpoints/final/h32_best.pt`，SHA256：
  `2645079664d7c399a29fb8bee44cbe26baa6cce6757e7691458ac10138d4d78b`。

- H8 正式契约 `configs/baseline_s2_e2.json` 与对应 S2 最佳权重保留，维持旧基线入口；
  其历史结果受旧调度/编译解冻问题限制，不能当成有效全模型解冻的证据。
- CPM-off 是已有实验中的简化对照，不是优于原模型的最终方案，其权重不再保留。
  T16/T17 的 BS96 不提升为通用更优默认值。

权重和正式结果文件校验见 [manifest](../results/final/manifest.json)。

## 统一解释口径

任务为自然 BOLD 预测，116 ROI；固定评价使用 K64 历史、完整 H32 未来，
val/test 各 225 人、每人 16 个锚点，共 3600。先锚点内 ROI/时间平均，
再被试内锚点平均，最后被试等权。单位沿用 raw BOLD 前缀校准后的数据尺度。
空间 PCC 与沿未来轨迹的时间 PCC 不混用；常数轨迹时间 PCC 保持未定义。

模型 seed=2024，采样 seed=20261009，条件 Dropout seed=20261008。
各 run 的实际参数、初始化和迁移以 checkpoint 快照为准；H8/H32 不同范围、
BS64/BS96 不同更新数、单轮适应、冻结读出子集等协议不可混作同一种对照。

## 全实验的主要决定

历史过程已压缩为此表和 [experiments_summary.json](../results/final/experiments_summary.json)。
后者保留关键实验的机器汇总，源目录字段仅作来源标识，不是待执行任务或有效链接。

| 实验 | 关键结果 | 最终取舍 |
|---|---|---|
| E0/E1/E2 损失 | E2 多步误差有小幅改善，未解决长程退化 | 保留 E2 |
| S0/S1/S2/S3 | S2 历史记忆有净收益；S1/S3 存在短程代价 | 保留 S2，不恢复反馈候选 |
| L1–L3、Temporal PCC | 微小收益或误差权衡，未得到实用整体收益 | 不采用，不继续扫损失组合 |
| S4/P1 概率路线 | 改善部分评分，联合时空依赖仍未胜出关键对照 | 不定型，未采用权重移除 |
| T01/T13 训练修复 | 修复调度、编译后解冻梯度与完整状态保存/恢复 | 代码保留，旧指标不重写 |
| T02/T10/T14 H32 监督 | 同架构、BS64、150轮预算下，全H32总体/远期MAE降低39.58%/50.69% | 保留完整 H32 监督 |
| T03 轨迹/扰动 | 远期跟踪弱；q-only平移是结构性质，一致历史/潜状态扰动有动态响应 | 不据此换架构或宣称真实刺激能力 |
| T04 校准/历史岭回归 | 公共系数约0.948788，test远期MAE只改善0.0228%；历史岭回归未超ODE | 不部署校准，不认定信息上限 |
| T05 train/val | 远期时间PCC约0.1783/0.1782，训练被试未明显更好 | 不把跨被试泛化作为唯一解释 |
| T06/T07 一致性/梯度 | cross-head关闭无实用收益；未发现整体远期梯度消失 | 不扩大系数或远期权重搜索 |
| T08 历史顺序 | 打乱旧历史块，val远期ODE MAE增加约14.2% | 模型利用历史顺序，但不是临床因果证据 |
| T09/T11 科研与数据核查 | 病理、访视身份、条件字段语义存在解释边界 | 保留限制，不静默改数据 |
| T12/T15 CPM监督 | 关闭后总体/远期MAE只增0.0281%/0.0229% | 无实用辅助贡献证据，尚未验证物理删头 |
| T16 统一目标+BS96 | 远期无实用改善，H1误差增加18.30% | 不替换原参考 |
| T17 一轮配对探针 | 分组目标局部修复H1，远期差约0.000007 | 仅局部证据，不补完整训练 |
| T18 冻结表示 | 共享线性读出均未超过原ODE，收益未集中于少数ROI/波动组 | 不换读出或增加专门分支 |

## 统一目标与一轮探针

T16是CPM-off统一目标BS96；旧对照是CPM-off分组BS64。两者各150轮，但scaler.step
调用为36,900/54,750，减少32.60%，EMA及随机分批也变化，不能归因于目标单因素。

| ODE MAE | 分组BS64 | 统一BS96 |
|---|---:|---:|
| H1 | 0.072358 | 0.085597 |
| H1–8 | 0.519283 | 0.524213 |
| H17–32 | 0.898801 | 0.898937 |
| H1–32 | 0.793668 | 0.794982 |

短程贡献总体误差增量约93.78%。T17从同一已训EMA-best出发，两臂BS96、各一轮，
合计492个batch，新建Adam及原生损失权重，不是严格resume或HC起点长期对照。
恢复分组后H1为0.083125，保持统一为0.085703，225/225人改善；
H1–32仅改善约0.012%，H17–32几乎不变。不以这点差异追加150轮训练。
