# 多尺度相位协同预测方案：运行与训练说明

当前模型名称为“多尺度相位协同预测方案”（原V2），模型、训练策略和配置保持唯一，唯一配置为 `configs/neurotwin.json`。不再提供旧结构开关、其他实验JSON或旧B权重迁移。历史报告是实验记录，不是当前运行配方。

## 保留的V2权重

两阶段各完成150轮训练，均使用第149轮的EMA best；last和完整training_state也保留。下表为未改写的权重文件。

同目录的 `base_last.pt` / `finetuned_last.pt` 为第150轮EMA，不能代替best。`training_state.pt`包含原始参数、EMA、优化器、调度器、scaler、采样器及随机状态，用于恢复，不作为默认推理权重。

本次只收敛代码，不转换权重、不重训。格式号仍为ARCH_VERSION=7，加载器另外要求完整V2参数键；不支持同格式号下的旧B/V0/V1结构。

```bash
python model.py --mode pretrain --device cpu
python model.py --mode finetune --device cpu
```

默认加载时同时核对SHA256、运行配置、条件布局及全部参数键。权重移动后可用 `--ckpt` 显式指定同一文件，仍核对哈希；不能用该参数加载旧方案。

目录采用“中文方案名_MMDD”格式，1108为训练开始日期。权重和训练状态内的原始运行路径保留为历史元数据；实际加载、热启动和恢复使用新目录及唯一配置，文件内容和SHA256不因更名改变。

## 唯一训练策略

| 设置 | V2值 |
|---|---|
| 历史/未来 | K64/H32，固定32 TR扫描校准 |
| 随机来源 | 模型2024；采样20261009；条件dropout 20261008 |
| batch / 预算 | 64 / 150轮 |
| 初始/峰值/最终学习率 | 0.00002 / 0.00005 / 0.00001 |
| warmup / weight decay / 梯度裁剪 | 3轮 / 0.01 / 1.0 |
| 冻结与解冻 | 前10轮；之后只解冻TFM最后两层、final_norm、RevIN及CPM |
| 参数组学习率 | 主干/原CPM为0.1倍，条件/预测适配器为1倍 |
| EMA / 验证 | 0.995；每轮均验证原始参数和EMA，固定用EMA选best |
| patience | 12；冻结期不累计，解冻时清零 |
| 增强 | 仅历史噪声标准差0.005；缩放、ROI丢弃、时间遮挡均为0 |
| 自动测试 | 关闭 |

冻结阶段，条件和预测适配器始终训练；HC还训练CPM，MDD的原CPM在解冻后参与训练。冻结的patch embedding、图先验和前两层保持eval模式。解冻不重建已有AdamW状态，新增参数组同步到相对余弦调度器。

六项损失权重：重建1.0、FC 0.02、频域0.02、差分Huber 0.3、全局Temporal PCC 0.2、局部PCC 0.03。H1–H32重建权重从1增至1.5；局部PCC窗口为H1–16、H9–24、H17–32。差分H1从真实历史末帧开始。

选模指标为完整H32 MAE加0.15倍的时间相关性损失。指标先按锚点计算，在被试内平均，最后跨被试等权。逐时距PCC沿ROI计算；阶段Temporal PCC沿未来时间轴计算。验证记录保存原始参数与EMA，不能将原始参数最优轮次替换为另一套默认best。

## 训练入口与恢复

HC默认从当前V2 HC best热启动；不再从原B初始化。MDD默认从当前V2 HC best开始，新增临床字段独立初始化，共享字段和全部动态参数严格继承。

```bash
DEVICE=cuda:0 bash scripts/pretrain.sh
DEVICE=cuda:0 bash scripts/finetune.sh
```

训练输出目录已存在时自动增加序号，避免覆盖现有best/last/状态。若使用新训练的HC启动MDD，以训练打印的实际best为准，通过 `HC_WEIGHT` 传入。

两阶段默认显式使用 `data/subject_split_pretrain.json` 与 `data/subject_split_finetune.json`。改变数据目录后使用该目录的同名manifest，也可以用 `--split_file` 指定已确认的固定划分；文件不存在或队列不一致直接报错。

使用 `RESUME_TRAINING_STATE` 恢复同一V2阶段。已完成150轮的状态默认不再训练；增加预算必须显式指定 `--train_epochs`，本次没有增加预算或启动训练。恢复时核对配置、统计量、划分及优化器参数登记，不只是加载best。

没有 `MODEL_CONFIG` 或 `--model_config` 参数，也没有关闭多尺度、局部相位或未来时距模块的开关。设备、数据路径、输出位置及批处理等常规运行参数仍通过现有命令行和环境变量传入。

## 评价与下游接口

```bash
python -m analysis.evaluate --mode finetune --splits val --device cuda:0 \
  --out_dir results/模型优化/当前V2验证评价 --save_arrays
python -m analysis.evaluation_report \
  --eval_dir results/模型优化/当前V2验证评价 \
  --out_dir results/模型优化/当前V2验证评价/汇总 --split val
```

评价和原始扫描推理默认读取唯一配置的V2权重。固定锚点评价、H1观测刷新、ROI归因、历史token和条件表征接口保留。报告器只处理V2的H32产物；旧B/新模型比较与旧实验汇总入口已移除。

当前只完成训练与验证，未新增测试集评价。HC/MDD的验证H32 MAE为0.781098/0.761006，Temporal PCC为0.487644/0.494290；这些是参与选模的验证指标，不是独立泛化结果。

整理前后使用相同合成历史及条件，HC/MDD现有best的完整H32预测与历史token逐位一致；两份best的SHA256未改变。直接受影响的模型、训练、损失、加载和报告测试及完整V2训练状态恢复检查见最终交付结果。本次未重训、未修改数据或历史实验数值。
