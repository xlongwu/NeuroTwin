# 多尺度相位预测实施说明

本实验在当前本地方案 B 上新增历史动态适配器。原 `configs/neurotwin.json`、正式 HC/MDD 权重、TFM 主干、功能图、ROI Attention、条件 FiLM、固定校准和被试划分均保留。实验配置为 `configs/neurotwin_multiscale_phase.json`，只在 `multiscale_phase=true` 时创建新增参数。

本轮实现、HC→MDD训练及同协议测试已完成。两阶段均第22轮早停、best为第10轮；第11–22轮确实执行了解冻联合训练，但没有选出更好的验证模型。当前实验配置已登记实际EMA best的哈希与轮次，原默认B未被替换。

[当前模型结构](多尺度相位模型结构.md) · [完整实施结果](../../results/模型优化/多尺度相位预测_20261107/说明/实施结果总结.md)

## 模型连接

| 模块 | 输入 | 输出及作用 |
|---|---|---|
| MultiScaleTemporalEncoder | RevIN 后历史 `[B,116,64]` | `[B,116,256]`，共享64通道投影，kernel=3、dilation=1/2/4/8残差因果卷积；拼接各尺度最新状态与完整历史聚合 |
| PhaseAwareForecast | 同一历史、多尺度状态 | 相位特征 `[B,116,32,256]`、振荡先验 `[B,116,32]` |
| DynamicForecastAdapter | 原8个patch token、多尺度和相位特征 | 原8个token保留，每ROI追加1个记忆token，并给全部未来查询加动态条件 |
| 输出门控 | 多尺度状态、未来相位特征和时距 | 小幅振荡残差与CPM预测在同一RevIN空间相加，之后统一进行一次反归一化 |

因果卷积仅左填充；归一化只沿通道，不跨时间。新增卷积用左移窗口与线性投影实现相同运算，保留Conv1d权重名和形状，避免项目确定性CuDNN设置的大batch慢路径；未关闭确定性。dilation1/2/4/8的双精度输出及梯度等价检查均通过（容差1e-12）。完整历史聚合也只读取当前 K64，最新TR直接进入各尺度末状态。

相位编码读取当前历史窗口的rFFT，保留实部、虚部、幅值及复数单位相位，不做扫描级离线小波或整段FFT预分解。使用 k=1–13 候选频点；TR=2秒、K64时，bin间距为0.0078125 Hz。标准FFT相位先旋转63帧到历史末帧，再由h=1开始外推，避免误将历史首帧相位当作预测锚点相位。

每个模式的权重、频移、幅值斜率及衰减由频域特征与多尺度状态共同决定。频移由tanh限制在半个bin，即±0.00390625 Hz；幅值调制在0.5–1.5内，模式可靠性与最终门控均为sigmoid有界输出。模型可降低不可靠模式贡献，不强制固定周期持续外推。

新增查询/记忆投影以小标准差初始化，查询残差系数初值0.01，最终振荡门控偏置-4。额外记忆token还有初值-6的可靠性logit。原patch记忆与新增历史记忆共享Q/K/V投影，分别进行交叉注意力，再以小门控做残差融合；既不改变原patch的softmax归一化，也保留Flash Attention内核。原条件FiLM继续作用于融合后的查询。

## 训练目标与参数分组

新损失继续使用原六项ForecastFidelityLoss，不另建训练器。H1–H32重建权重从1线性增至1.5，有效mask按权重后的有效元素数归一。全H32时间PCC保留，局部PCC使用H1–16、H9–24、H17–32三个重叠窗口。H1差分使用真实历史末帧。

| 损失/设置 | 新实验初值 |
|---|---:|
| 重建 | 1.0 |
| 差分Huber | 0.3 |
| 全局时间PCC | 0.2 |
| 局部时间PCC | 0.03 |
| FFT magnitude | 0.02 |
| FC MSE | 0.02 |
| 选模 | 完整H32被试等权MAE加0.15倍的时间PCC损失 |

增强参数来自新JSON配置：noise_std=0.005，其余输入缩放、ROI丢弃、时间遮挡概率均为0。只扰动历史输入，不改变未来真值、future mask或真实历史末帧监督参考；原B继续使用原增强默认值。

原TFM主干沿用0.2倍学习率；CPM与条件模块保留原分组。新增模块通过`is_prediction_adapter`登记，使用1倍学习率，HC和MDD冻结前10轮都参与训练。解冻时保留已有AdamW状态，新增参数组同步纳入原相对余弦scheduler；继续使用EMA、梯度裁剪及原数据采样规则。

每轮验证保存完整逐horizon MAE/RMSE/Spatial PCC，以及H1–8、H9–16、H17–32、H1–32的MAE/RMSE/Temporal PCC。单horizon不输出Temporal PCC。

## 权重迁移与兼容

本地原正式权重实际位于：

- HC：`checkpoints/CPM直接长程预测方案_1106/neurotwin_pretrain/base_best.pt`。
- MDD：`checkpoints/CPM直接长程预测方案_1106/neurotwin_finetune/finetuned_best.pt`。

其SHA256与原正式配置登记值一致。原配置登记的历史目录未改，运行对比时显式使用上述实际路径。新实验从当前HC best加载全部同名同形状的有效TFM、CPM、图及条件参数，新增模块独立初始化，迁移记录写入checkpoint的`config.initialization`，包括来源哈希、逐键映射和新增键清单。

没有使用全局`strict=False`。只允许显式登记的动态模块新增键，以及HC→MDD新增临床字段键；其他缺键、额外键或形状冲突报错。新HC best的动态模块完整迁移到MDD，HC共享字段统计量继续逐位继承。新旧checkpoint均由`model.load_model_checkpoint`严格重建；旧配置不会创建新增模块。

## 直接运行

已有权重可直接严格重建，不需要重新训练：

```bash
python model.py --model_config configs/neurotwin_multiscale_phase.json --mode pretrain --device cpu
python model.py --model_config configs/neurotwin_multiscale_phase.json --mode finetune --device cpu
```

原B仍可显式指定移动后的实际权重，同时核对原配置与哈希：

```bash
python model.py --mode finetune \
  --ckpt checkpoints/CPM直接长程预测方案_1106/neurotwin_finetune/finetuned_best.pt --device cpu
```

在仓库根目录执行。以下命令以物理GPU1为例；更换设备只修改`CUDA_VISIBLE_DEVICES`。首次运行使用新目录，重复运行时训练入口会另建后缀目录；MDD的`HC_WEIGHT`必须指向本次实际生成的HC best。

```bash
CUDA_VISIBLE_DEVICES=1 MODEL_CONFIG=configs/neurotwin_multiscale_phase.json \
DEVICE=cuda:0 bash scripts/pretrain.sh

CUDA_VISIBLE_DEVICES=1 MODEL_CONFIG=configs/neurotwin_multiscale_phase.json \
DEVICE=cuda:0 \
HC_WEIGHT=checkpoints/多尺度相位预测_20261107/neurotwin_pretrain/base_best.pt \
bash scripts/finetune.sh
```

训练继续沿用150轮上限、冻结10轮及验证早停；不使用测试集调参。MDD训练结束默认执行一次测试评价。需要保存同协议对比数组和历史时，按下面命令分别评价原B和新模型：

```bash
CUDA_VISIBLE_DEVICES=1 python -m analysis.evaluate \
  --ckpt checkpoints/CPM直接长程预测方案_1106/neurotwin_pretrain/base_best.pt \
  --out_dir results/模型优化/多尺度相位预测_20261107/原B健康评价 \
  --device cuda:0 --splits test --save_arrays

CUDA_VISIBLE_DEVICES=1 python -m analysis.evaluate \
  --ckpt checkpoints/多尺度相位预测_20261107/neurotwin_pretrain/base_best.pt \
  --out_dir results/模型优化/多尺度相位预测_20261107/新模型健康评价 \
  --device cuda:0 --splits test --save_arrays

CUDA_VISIBLE_DEVICES=1 python -m analysis.evaluate \
  --ckpt checkpoints/CPM直接长程预测方案_1106/neurotwin_finetune/finetuned_best.pt \
  --out_dir results/模型优化/多尺度相位预测_20261107/原B抑郁症评价 \
  --device cuda:0 --splits test --save_arrays

CUDA_VISIBLE_DEVICES=1 python -m analysis.evaluate \
  --ckpt checkpoints/多尺度相位预测_20261107/neurotwin_finetune/finetuned_best.pt \
  --out_dir results/模型优化/多尺度相位预测_20261107/新模型抑郁症评价 \
  --device cuda:0 --splits test --save_arrays
```

生成四类PDF图和分开保存的CSV表：

```bash
python -m analysis.evaluation_report \
  --original_eval results/模型优化/多尺度相位预测_20261107/原B健康评价 \
  --eval_dir results/模型优化/多尺度相位预测_20261107/新模型健康评价 \
  --out_dir results/模型优化/多尺度相位预测_20261107/健康模型比较

python -m analysis.evaluation_report \
  --original_eval results/模型优化/多尺度相位预测_20261107/原B抑郁症评价 \
  --eval_dir results/模型优化/多尺度相位预测_20261107/新模型抑郁症评价 \
```

现有比较目录已包含本轮图表，无需再次生成覆盖。汇总两个队列的已完成结果，不重新训练或推理：

```bash
python -m analysis.evaluation_report \
  --experiment_dir results/模型优化/多尺度相位预测_20261107 \
  --out_dir results/模型优化/多尺度相位预测_20261107
```

对比会核对划分哈希、历史长度、TR、校准及归一化口径，并按被试和锚点逐项核对历史、真值、mask、锚点末帧。不一致时不能画成同协议比较。轨迹图按被试ID排序取首/中/末、最早锚点、首/中/末ROI，不按预测效果挑选。动态表包含Std Ratio、Delta PCC/MAE、PSD Shape PCC、Log-PSD MAE、FC MSE/Pattern PCC。

## 本轮结果与边界

HC、MDD完整H32测试MAE分别由0.793584/0.786520降至0.782391/0.778153，下降1.41%/1.06%；Temporal PCC由0.456849/0.460115提高到0.471997/0.470539。H1–8的MAE下降6.94%/5.85%，收益主要集中在短程。

H17–32的MAE下降仅约0.22%/0.05%；MDD有6个远期点MAE略有退化。完整H32的Std Ratio由HC 0.488157、MDD 0.483454降至0.483908、0.478209，幅值收缩没有缓解。新模型仍作为已训练实验候选与原B并存，不能宣布已解决长程预测问题。

四类真实结果图已按两个队列生成，共8张PDF，并完成渲染检查。汇总表、逐时距退化位置、动态指标、实际训练及权重来源见[实施结果总结](../../results/模型优化/多尺度相位预测_20261107/说明/实施结果总结.md)。本轮未做同预算B续训对照、模块消融或多随机种子重复，不能把整套方案的收益单独归因于相位分支，也未声称统计显著性。
