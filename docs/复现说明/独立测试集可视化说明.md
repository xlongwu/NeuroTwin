## 数据范围

- HC 为固定 `subject_split_pretrain.json` 的全部 test 222 人；MDD 为固定 `subject_split_finetune.json` 的全部 test 225 人。逐项检查 test 与各自 train/val 无交集；每份带被试标识的输出都检查属于 test。
- 这是已经用于既有评价的内部被试留出测试集，不是未查看过的新外部队列。
- 主分析统一使用冻结健康参照 `checkpoints/neurotwin_pretrain/base_best.pt`，继承训练时 hc3 条件统计。图中不出现训练、验证或原混合子集被试。
- 滚动单步与已有 test z 评分直接复用已保留的完整 test 数据；z 的参照来自原 HC train 拟合。新的轨迹、学习图、条件、ROI 重要性和历史/输入扰动覆盖全部 HC/MDD test，无 20 对抽样。
- 自主生成使用最初 K64 预测未来 H32，不反馈真实未来；每人最早 32 TR 固定校准。当前权重辅助训练时程为 8，H32 是外推，不引用历史 H32 权重成绩。
- MDD 微调模型只在补充图中展示其已保留的完整 MDD test 指标。它使用 mdd8 条件，不能将与健康参照的差别归因于单一结构因素。

## 组间对照与口径变更

test 内重新匹配遵循已有规则：站点内各组至少 10 人、同性别、年龄差不超过 5 岁，确定性最近邻且无放回。本批得到 47 对、4 个站点；47 对只用于匹配对照，不取代完整 222/225 人的模型评价。教育不参与匹配约束。

HC 负控仅使用 HC test，在各站点固定种子随机分半，两个半集各 104 人；不能使用 val−test 负控。单例站点不进入这个负控。

匹配/未匹配/负控图仅描述新的 test 均值差，原 1504 对、旧 FDR 数值、临床 p 值和混合划分 OOF ROC 均不移入本批。匹配森林图的逐对 bootstrap 区间没有选择后或多重比较校正，不能以是否跨零直接指定病理脑区。

原静态 FC 岭分类器的 OOF 数组已清理。F7 因此仅在原 HC/MDD train 上重新拟合固定的 `RidgeClassifier(alpha=1)` 基线，使用最初 K64 的 6670 条 FC 边，不用 val/test 选参或选择阈值；ROC 全部来自独立 test 的分数，不移用旧 OOF。另并排展示预先固定的 mean|z| 标量，规定高分为 MDD，不为提高 AUC 翻转方向。两个方法分别报告完整 test 与 test 匹配子集，均不代表队列可分性上限。没有重新训练 NeuroTwin 主模型。

FC 与 z 的观察窗口不同：前者只用最初 K64，后者来自完整滚动误差。不能由两条 ROC 的 AUC 差直接量化模型增益。蓝色 ROC 带是固定分类器 test 分数 500 次 bootstrap 的逐点 95% 区间；全样本按组/站点分层，匹配样本按站点内匹配对重采样，不包含重新拟合分类器或训练样本的不确定性。

F9 采用 AAL116 表中的完整展示网络，控制年龄、性别和站点；不是旧稀疏网络结果的直接复现。HAMD 可用 225 人、HAMA 可用 54 人，缺失病例不插补，记录控制矩阵秩，不新增显著性星号。HC 不具备对应疾病症状评分，不伪造 HC 临床关联图。

## 可解释性设置

- 条件：全部 test 的最初 K64 起点，使用原全缺失编码比较；不是旧全部滚动锚点 B5 的直接复现。
- ROI 重要性：每组完整 test 内固定供体排列，逐 ROI 替换 K64 历史；保留目标个体条件、校准和 profile，图从扰动输入重算。主终点为 ODE lag-1 MAE，不混用主输出头或疾病分类指标。相同未扰动批次的结果只计算一次，供 116 个 ROI 比较复用；不使用旧四批近似 FDR。
- 时间顺序：8 个连续 8 TR 历史块，逐块内部同步置换，3 次固定种子重复。先在个体内平均重复；最后一块也会改变最后观测值，不能单独归因于纯时间顺序理解。
- 输入扰动：每人、116 个源 ROI、正负两个方向完整执行最后 8 TR 的 ±0.1 改变；输出相对同形状未扰动批次的绝对预测变化，并除以 0.1。排除直接自响应后描述跨区传播。每人 sham 最大差须不超过 1e-6；仅说明模型结构敏感性，未校准为真实刺激、损伤或治疗响应。
- profile：全部使用 eval 模式，只展示当前 test 描述性差异；旧受 dropout 影响的参数 q 值不搬用。PCA 为在所画 test 样本上拟合的描述性嵌入，不是分类器或外部验证结果。

## 复现入口

再次运行应显式使用新的三个批次目录；可视化绘制入口拒绝覆盖非空目录。所有命令在仓库根目录运行。

1. `python -m analysis.test_visualization.prepare --data-dir 新数据目录 --table-dir 新表格目录 --figure-dir 新PDF目录`
2. `python -m analysis.test_visualization.infer --stage base --data-dir 新数据目录`，生成完整 test 基础输出。
3. `python -m analysis.test_visualization.stats --stage base --data-dir 新数据目录 --table-dir 新表格目录`，仅消费完整 test 输出。
   静态 FC 基线另运行 `python -m analysis.test_visualization.ridge --data-dir 新数据目录 --table-dir 新表格目录`；拟合仅用 train，输出表只保存 test 评分。
4. 分别执行 `infer --stage probe` 与 `infer --stage importance`，均指定同一个新数据目录。
5. 执行 `stats --stage probe`，指定新数据目录与新表格目录。
6. `python -m analysis.test_visualization.plot --data-dir 新数据目录 --table-dir 新表格目录 --out-dir 新PDF目录`
7. `python -m analysis.test_visualization.check --data-dir 新数据目录 --table-dir 新表格目录 --figure-dir 新PDF目录`

本次 CPU 分片：base 为 16 份、每份 1 线程；probe 和 importance 起初为 24/8 份，部分进程被运行环境以 SIGTERM 终止后，校验已完成缓存并降为 8/4 份、每份 2 线程续算。通过 `--partition i --partitions N --threads 2` 分配互不重叠的被试或 ROI，已有单项缓存跳过；改变 CPU 分片不改变样本、随机排列、权重和统计定义。执行记录另存 `execution.json`。

没有重新训练或优化 NeuroTwin，没有 git 提交。静态 FC 仅在 train 上拟合固定线性分类基线。基础检查结果保存在本批 `数据/.../checks.json`；最终检查包含 test 全覆盖、无 train/val 混入评价、FC 基线仅 train 拟合、来源文件不变、数值/维度/sham、既有 test CRPS 一致性、PDF 页数及可视化目录仅含 PDF。
