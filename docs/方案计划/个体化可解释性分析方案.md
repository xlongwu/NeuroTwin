# NeuroTwin 个体化可解释性分析方案

日期：2026-10-30  
状态：方案设计；尚未实施或产生新结果。

## 1. 目标与范围

以现有模型和数据研究：**模型利用个体自身的哪些脑区历史进行预测，这些依赖在脑网络和人群中如何分布，以及它们在同一扫描内是否稳定。** 先描述每人的模型表征，再分析扰动该人的输入后预测如何变化；以群体共同规律和个体差异为主要呈现，个体案例辅助说明。

主要研究对象是 HC 测试集和 HC 预训练模型；MDD 测试集和微调模型按相同分析框架做扩展。主协议为滚动单步的锚点抽样，固定锚点 H1–8 为补充。仅使用已有 checkpoint，不重训模型、不改变训练设置，也不要求外部或重复扫描数据。

不以跨被试供体替换或“本人信息优于他人信息”为目标。分析完全可以在被试自身信息内完成，但依赖结论仍需通过明确的输入扰动或基线对照建立。所有研究问题均为探索性：本测试集已用于其他可解释性探索，不能称为全新、从未观察过的独立验证集。

## 2. 项目背景和已有证据

- 输入为固定前缀校准后的 116 ROI BOLD，常规历史长度 K=64 TR；每人扫描最早 32 TR 用于固定校准和 profile。HC 条件包括性别、年龄、受教育程度；MDD 模型增加临床字段。
- 当前历史经可逆归一化、时空 Transformer 和图引导注意力编码，Graph-ODE 输出预测。历史图来源于当前可见历史 ROI 相关绝对值；有效图还包括从历史学习的图、残差和归一化。profile 来自前缀的共享编码器与 profile 编码器。
- HC test 为 222 人，MDD test 为 225 人。固定锚点 H1–8 的 HC/MDD 平均 MAE 分别约 0.534/0.532；滚动单步 MAE 分别约 0.0904/0.0920。两种协议的数值不能互换。
- 既有可解释性分析包括条件使用、首锚点图、ROI 替换、历史顺序和输入扰动。首锚点的空间结果不能代表整个扫描；此前的 ROI 重要性使用他人历史替换，回答的问题与本方案不同。
- HC val 全条件与全缺失条件比较的相对预测差中位数约 0.00435；MDD test 对应约 0.00411。比较涉及不同人群、权重和字段，不能作为疾病组间结论。当前健康参照分析中组间 ROI 未发现 FDR 显著偏离。

上述结果和限制见[现有分析报告](../../results/当前模型分析结果/个体化可解释性分析/说明/H1-8分析/分析报告.md)、[H1–8 分析方案](H1-8分析方案_20261028.md)和[模型说明](../../models/README.md)。部分旧文档中的权重目录和“尚未重算”描述早于现有分析报告；实施时以实际 checkpoint、哈希、划分与缓存清单核验来源。

## 3. 问题与输出

| 编号 | 问题 | 主要输出 | 定位 |
|---|---|---|---|
| Q1 | 扰动某 ROI 自身历史的局部时间顺序后，全脑单步误差如何变化？ | 每被试、每 ROI 的 MAE 变化；全脑 ROI 排序与不确定性 | 主分析 |
| Q2 | 上述变化在既有网络中如何分布，人与人之间是否一致？ | 网络级变化、个体分布、排名与方向一致性 | 主分析 |
| Q3 | 模型有效图及 profile 在个体和扫描时段间呈现什么结构？ | 图、网络块、profile 的描述及扫描内稳定性 | 支撑分析 |
| Q4 | 输入变化影响了哪些目标 ROI，作用是否随预测时距变化？ | 源 ROI 到目标 ROI 的输出响应，H1–8 误差变化 | 补充分析 |
| Q5 | 条件和 profile 的改变是否影响单步预测？ | 输出差、误差差及个体分布 | 补充分析 |
| Q6 | 同样的现象能否在 MDD 微调模型内部观察到？ | MDD 独立汇总及其覆盖情况 | 扩展分析 |

“输入 ROI 重要性”指改变该 ROI 历史后全脑预测误差的变化；它不同于该 ROI 自身预测误差，也不同于输出变化幅度。正值表示该扰动使误差增加；负值表示误差降低，不应被强行归零。

## 4. 数据、模型与采样

### 4.1 输入与权重

- HC：`checkpoints/neurotwin_pretrain/base_best.pt`，划分 `data/subject_split_pretrain.json`，使用 checkpoint 的 hc3 条件配置和统计量。
- MDD：`checkpoints/neurotwin_finetune/finetuned_best.pt`，划分 `data/subject_split_finetune.json`，使用 checkpoint 的 mdd8 条件配置和统计量。
- 先核对文件实际存在、SHA256、checkpoint 配置、ROI 顺序、数据版本与划分。预期 HC 哈希为 `041689f82ad205f41bad3c8d5d688c4d8818a87eb538fa3dfec870910ef961bc`，MDD 哈希为 `f89f57026bb789b0fb8e131a8042e7f220b2e2e827521b988ff3398806ecf4ac`；若不一致先核查，不将不同权重的结果合并。若实际保留路径不同，以哈希和加载配置确认，而不是凭目录名推断。
- 沿用项目 Raw BOLD、最早 32 TR 校准和模型内 RevIN；预测时不利用目标或未来观测。测试被试不参与模型或条件统计量拟合。

### 4.2 锚点与计算预算

覆盖每组所有满足数据与协议要求的 test 被试。每人从合法滚动单步锚点中按扫描内相对位置均匀选取 **8 个锚点**，含首末合法位置；若不足 8 个则使用全部并记录实际数目。锚点整数化、去重及边界与现有滚动加载器保持一致；不以结果好坏筛选。各锚点输入真实的当前 K64 历史，仅预测下一 TR，因此是滚动单步协议的抽样评价，不是完整 dense rolling。

每个 ROI、每个锚点使用 **3 次**预先固定的置换，seed=2024；保存实际索引。按 222 人、8 锚点、116 ROI、3 次计，HC 主扰动约 618,048 条样本前向，另有基线和质控；批处理不改变前向样本总量。MDD 同规模约 626,400 条。先对少量测试被试做不用于调整效果方向的功能和耗时检查，估算 GPU 时间与存储；若资源不足，正式运行前记录并冻结抽样调整，已查看效果后更改的分析标为探索性。H1–8 补充优先复用同一批扰动，必要时限定预先固定的锚点子集并注明覆盖。

## 5. 主分析：个体内 ROI 历史顺序扰动

### 5.1 基线与扰动

1. 对每人每锚点，使用其原始 K64 历史、最早 32 TR profile、对应条件和正常模型前向，记录 H1 全脑预测、真值及有效图。
2. 每次只选一个源 ROI，将其 K64 分为连续 8 个、每块 8 TR。对每块内部独立置换时间位置；最后一块只置换前 7 个位置，保持最后观测值不变。其他 ROI 保持不变。每次重复独立生成置换，并记录种子与索引。
3. 按模型正常前向从扰动后的完整历史重新计算历史 FC 和有效图；使用目标被试原有的固定前缀校准、profile、人口学条件及预测目标。不要把扰动历史重新用于计算 profile。
4. 保存原始和扰动后每个目标 ROI 的预测与误差，至少保留足以重现逐被试、逐源 ROI、逐锚点及逐重复汇总的数据。随机序列只用于扰动，不修改原始数据。

每块内置换保留该块的数值集合，但破坏局部时间顺序，也会改变与其他 ROI 的同期关系和由此构造的图。故结果是**时序与图路径共同作用下的模型敏感性**，不单独归因于时间注意力或图模块，也不是生物学因果效应。最后一帧保持不变可以排除直接改变预测起点的影响，但不能消除其他分布偏移。

### 5.2 终点与聚合

对被试、锚点、源 ROI 和一次置换，计算扰动后减去原始预测的全脑 116 ROI 平均绝对误差，记为 `ΔMAE`。正值表示误差上升。先对每人的有效锚点和置换取平均，再跨被试等权汇总；不得把重复置换或锚点当作独立受试者。

同时报告原始 MAE、扰动后 MAE、绝对 `ΔMAE`、相对于原始 MAE 的变化、被试间分布和正值被试比例。相对变化仅在分母有效且非零时计算，明确它是被试内比值的汇总还是组均值之比。补充将误差分为源 ROI 自身与其余 115 ROI，并展示目标 ROI 输出变化；全脑均值可能稀释局部效应。

### 5.3 ROI 与网络

- ROI：完整报告 116 个源 ROI 的均值、中位数、被试级 95% bootstrap 置信区间及正值比例；给出完整排序和图表，不只展示最高项。
- 网络：沿用项目 AAL116 网络映射，对每名被试先在网络内平均源 ROI 的 `ΔMAE`，再跨被试汇总；报告 7 个网络、ROI 数和覆盖情况。网络统计描述输入来源，并非目标网络误差。
- 若进行显著性检验，以被试为单位开展配对符号翻转置换，说明零假设及对差值分布对称性的假设；116 ROI 与 7 网络分别作为检验族进行 BH-FDR，报告原始 p、q、效应和区间。置换和 bootstrap 可沿用 10,000 次、seed=2024。显著不等于效应足够大；未显著也不等于证明没有作用。
- 为避免根据结果选择阈值，不预设缺乏依据的最小实际收益；同时呈现绝对和相对效应，按其幅度及不确定性措辞。

## 6. 个体表征与稳定性

### 6.1 图表征

每个锚点记录历史绝对 FC、学习功能图和有效图 `A_eff`；记录图混合系数和图构造配置。描述单人及被试等权群体网络块、非对角边分布和随时间变化，统计图块时明确对角与自环的处理。对同一被试不同非重叠历史窗比较图的相似性，并提供时间间隔、有效窗数和站点组成；扫描长度不足者按实际覆盖报告。

图是由同一人的历史构造的模型量，不是实测解剖结构连接、有效连接或干预网络。有效图包含多个组成部分，不能仅由混合系数解释。

### 6.2 Profile

记录最早 32 TR 的 32 维 profile，描述其分布与对应预测表现；维度本身没有预设生物学语义。可以用非重叠扫描片段计算 profile 做扫描内相似性探索，固定片段长度并记录间隔、数量及覆盖。后续片段不符合原始首 32 TR 校准位置，属于分布外的探索性探针，不能作为正常前向的替代配置；也不能将扫描内稳定性解释为跨扫描重测。

图和 profile 的跨被试相似性、降维或个体识别如用于描述，应报告比较范围、基线和站点；避免将站点、扫描状态或运动伪影造成的可区分性解释为个体特异的神经信号。短窗功能连接的稳定性受时间长度影响，参考 [Finn 等的功能连接指纹研究](https://pmc.ncbi.nlm.nih.gov/articles/PMC5008686/)。

### 6.3 重要性自身的稳定性

按预先定义的扫描相对位置，将锚点分为早、晚两组，在每人内部比较 ROI 排名、网络水平及效应方向；报告组内锚点数及两组之间历史窗重叠情况。样本太短无法获得非重叠窗时应标明，不以重叠窗宣称独立复现。群体层面汇总被试的相关性和方向一致程度，不把同一扫描的时间切片称为独立扫描。

## 7. 补充分析

### 7.1 预测响应与 H1–8

对主分析同一扰动，记录各目标 ROI 的有符号及绝对预测变化，并先在被试内汇总，展示源网络到目标网络的响应矩阵；该矩阵是模型响应，不是真实连接或刺激传播。报告自身响应和跨 ROI 响应，避免自响应掩盖其他区域。

固定同一锚点做无真值反馈的 H1–8 前向，分别报告每个 horizon 的误差变化；不将它与滚动单步结果拼接。若计算预算需要缩减，缩减规则应在查看补充结果前固定，并注明样本范围。

### 7.2 Profile 与条件使用

以现有全条件与全缺失条件比较为基础，补充当前锚点上的预测输出差和误差差；全缺失编码是人为对照，不代表逐字段贡献，也不等于临床效应。HC 和 MDD 分开描述。

如要量化 profile 的作用，可增加在同一被试、相同历史和条件下将 profile 替换为固定中性值的探索性探针；中性值须先定义并核验编码尺度，零向量不自动等同于“没有个体信息”，也可能偏离训练分布。报告输出差与误差差，并保留原始前向。其他时间段的自身 profile 只能在不使用目标未来信息的前提下作为预测对照；否则仅用于事后表征描述。

这些补充探针不改变主分析为 ROI 时间顺序扰动的定位。当前不要求固定原始图或拆解编码器与 ODE 的图路径；如将来开展，需另行定义接口及解释范围。

### 7.3 MDD 扩展

使用 MDD 微调权重和 MDD test，重复相同定义和汇总，保持组内被试等权。分别展示 HC 与 MDD 的效应、置信区间和站点组成；两组模型权重和条件字段不同，图中并列不构成疾病效应检验。HAMD/HAMA 已作为 MDD 模型条件，若后续研究关联，须处理输入字段与关联对象重叠，当前不预设临床结论。

## 8. 质量检查与执行顺序

1. **来源核对**：冻结 checkpoint 哈希、模型配置、数据划分、网络映射、校准方法、锚点选择、随机种子和输出目录；区分现有 dense rolling 缓存与本次抽样结果。
2. **功能与成本检查**：少量测试被试检查张量维度、原始预测与现有前向一致、扰动仅影响指定 ROI 的指定位置、最后一帧不变、图确实重算、profile 和条件固定；同输入重复前向检查数值一致性，记录精度和设备。仅估算耗时，不根据效果方向优化规则。
3. **HC 主分析**：按冻结清单运行基线与 ROI 扰动，保存进度、失败原因和有效样本；不覆盖已有结果。
4. **汇总与稳定性**：生成 ROI、网络、时段及响应矩阵；检查缺失、常量 ROI、非有限值和实际样本数。无效输入显式报告，不以零或理想值填充。
5. **补充与 MDD 扩展**：按相同定义执行 H1–8、profile/条件探针和 MDD；资源不足时明确未完成部分。
6. **结果审阅**：检查效应方向、置信区间、个体差异和多重比较；报告负结果，避免看见结果后挑选脑区或重新定义主终点。分析规则若因错误修复而变化，记录原因和版本。

建议新建独立结果目录 `results/个体化可解释性_20261030/`，保存数据清单、逐被试逐锚点统计、ROI/网络汇总、图件和报告。图件提供 PNG/PDF 及对应数据表，记录运行命令、环境、设备与版本；本方案本身不执行推理、不生成结果，也不覆盖用户已有结果。

## 10. 可支持的结论与限制

- 可以讨论：在给定的块内时间置换及模型前向下，特定 ROI 历史对预测误差的影响、其网络分布和扫描内稳定性。
- 不可直接推断：真实神经因果机制、解剖或有效连接、病灶定位、真实刺激或治疗效应、跨扫描个体身份稳定性、临床诊断能力。
- 图会随扰动重算，不能将主结果归因于单独模型通路；人为打乱也可能产生分布外输入。
- 测试集曾用于其他探索；单队列、单次训练与扫描内切分限制外部泛化。若需要确认性证据，未来需独立数据或在未观察的数据上预注册验证。
- 若整体或某些区域的 `ΔMAE` 接近零或为负，直接报告及讨论区间、个体差异和扰动局限；不据此自动更改模型或搜索显著结果。
