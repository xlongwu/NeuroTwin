# NeuroTwin 模型结构、数据增强与训练策略总结（论文参考版）

> 本文与当前代码（`NeuroTwin` 项目）逐一核对过，可作为论文方法章节的参考底稿。

## 1. 任务定义与总体思路

本项目面向脑网络动态连接（dFC, dynamic functional connectivity）预测任务，核心目标是基于历史窗口的 ROI 时序信号与结构连接（SC）信息，预测未来窗口信号，并在 MDD（抑郁症）场景下引入病理分数实现个体化建模。

整体采用"两阶段训练"：

- 阶段一（Pretrain）：在 HC（健康对照）数据上学习通用脑动力学底座。
- 阶段二（Finetune）：在 MDD 数据上加载预训练权重，通过病理感知 MoE（NeuroTwinMoE）学习病理残差，完成个体化适配。

核心实现入口：

- 训练主入口：[main.py](main.py)
- 数据加载与增强：[utils/dataloader.py](utils/dataloader.py)、[utils/augmentation.py](utils/augmentation.py)
- 主模型：[models/neurotwin.py](models/neurotwin.py)（`NeuroTwin`）
- 公共模块：[models/common.py](models/common.py)（BrainRevIN / DFCAdapter / BrainMDM / GraphODE / GraphODEDDI / IterativePredictionRefiner）
- MoE 病理残差模块：[models/neurotwin_moe.py](models/neurotwin_moe.py)（`NeuroTwinMoE`）

## 2. 数据组织与样本构造机制

### 2.1 数据目录与输入输出张量

在 `data_root` 下，预训练与微调对应两套数据分组：

- HC 组：`ROISignals_window/HC` + `Mask/HC`
- MDD 组：`ROISignals_window/MDD` + `Mask/MDD`

单个样本构造后关键张量维度为：

- `x`: `[F, in_window, S]`，历史输入
- `y`: `[F, pred_window, S]`，未来监督信号
- `sc`: `[F, F]`，结构连接矩阵
- `pathology_score`（仅 finetune）：`[1]`（HAMD 分数）

其中，`F` 为 ROI 数（默认 116），`S` 为每窗序列长度（默认 30）。

### 2.2 滑窗样本生成逻辑

`NeuroTwinDataset` 对每位受试者读取固定数量窗口（默认 `total_windows=9`），以滑动起点 `start_idx` 生成训练样本：

- 输入窗口数：`in_window`（默认 6）
- 预测窗口数：`pred_window`（默认 3，脚本中用 1）
- 最大起点：`total_windows - in_window - pred_window + 1`

这使同一受试者可产生多个样本，提升样本量并保留个体动力学连续性。

### 2.3 SC 预处理

数据加载阶段对 SC 做了专门归一化：

- 清洗 NaN/Inf
- 对称化：`0.5*(SC + SC^T)`
- 截断负值
- `log1p` 压缩长尾
- 以正值 99 分位缩放
- 最终裁剪至 `[0,1]`

这一流程使 SC 作为图先验更稳定，避免极端连接值导致训练不稳。

### 2.4 Subject-level 划分（防泄漏）

`NeuroTwinDataLoader` 默认使用 subject-level 划分：

- 同一 `subj_id` 的所有样本仅出现在 train/val/test 之一，避免样本级泄漏。
- finetune 模式可按 HAMD 分数分位（`qcut`，`stratify_bins` 分箱）做受试者分层，缓解训练/验证病理分布偏差。

这对临床任务尤其关键：可显著提升验证结果可信度。

## 3. 数据增强策略（训练集专用）

增强由 `BrainSignalAugmentation` 仅作用于训练集的 `x`（不作用于 `y` 与验证/测试集），包含四类轻量增强：

1. 幅度缩放（Multiplicative Scaling）
- 每个 ROI 乘随机系数：`1 + N(0, scale_std)`，默认 `scale_std=0.05`。

2. 加性噪声（Additive Noise）
- `x + N(0, noise_std)`，默认 `noise_std=0.03`。
- 模拟采集噪声/系统抖动。

3. 通道随机失活（Channel Dropout）
- ROI 级随机置零，默认 `channel_drop_prob=0.03`。
- 降低模型对单 ROI 过依赖。

4. 连续时间掩蔽（Contiguous Time Mask）
- 以概率 `time_mask_prob=0.15` 启用。
- 掩蔽长度最多为 `S * max_mask_ratio`（默认 10%）。
- 被遮挡片段用该 ROI 均值填充。

该增强组合兼顾"信号扰动鲁棒性"和"时间片缺失鲁棒性"，且不过分破坏脑信号统计结构。

## 4. 模型结构解析（模块级）

### 4.1 总体拓扑

`NeuroTwin` 的前向流程可表示为：

1. `BrainRevIN`（可选）对历史信号标准化
2. 编码器：`DFCAdapter -> BrainMDM -> (GraphODEDDI × n_block，带可学习块级残差缩放) -> post_fusion（shallow 与 deep 特征拼接融合）-> GroupNorm`
3. 预测头 `NeuroTwinForecastHead` 产出 `base_pred`
4. 若为 finetune：`NeuroTwinMoE` 估计病理残差 `delta_pred`，输出 `base_pred + delta_pred`
5. `BrainRevIN` 反归一化（可选）

即：**通用动力学预测 + 病理残差修正**。

### 4.2 归一化模块：BrainRevIN

`BrainRevIN` 在 ROI 维度上对 `[B,F,W,S]` 做可逆标准化（带可学习仿射），用于：

- 缓解个体间信号尺度差异
- 提高优化稳定性
- 保证预测输出可通过 `denorm` 回到原信号空间

### 4.3 结构先验适配：DFCAdapter

`DFCAdapter` 是 SC 引导的多阶图扩散模块，关键点：

- 学习型边权 `edge_logits` 与 SC 逐元素结合
- 计算 0/1/2-hop 扩散并按可学习 `order_logits` 加权融合
- SE 通道门控 + 残差混合 + GroupNorm

作用：将结构连接先验显式注入功能信号表征，提升跨 ROI 传播建模能力。

### 4.4 双轴多尺度混合：BrainMDM

`BrainMDM` 同时在两个轴上建模，共 8 路分支融合：

- 原始输入（1 路）
- 序列轴 `S`：深度可分离卷积（核 3/5）2 路 + 多尺度自适应池化 1 路
- 窗口轴 `W`：窗口卷积（核 3/5）2 路 + 多尺度自适应池化 1 路
- 交叉分支 `cross_branch`：1×1 卷积交叉融合（1 路）
- 融合：`Conv2d(F*8 -> 2F -> F)` + SE 通道门控 + GroupNorm + 残差

作用：兼顾局部纹理与跨窗口演化，缓解仅时序卷积易出现的长程建模瓶颈。

### 4.5 动力学演化核心：GraphODE + GraphODEDDI

`GraphODE` 包含 4 条增量分支并通过 sigmoid 门控融合：

1. SC 约束图注意力分支（SC 作为 hard mask + soft bias）
2. 局部时间卷积分支
3. 跨窗口注意力分支（`nn.MultiheadAttention`，`window_heads=5`）
4. 前馈分支（FFN）

`GraphODEDDI` 使用 Heun / RK2 多步积分迭代上述动力学，支持 stochastic depth 与可学习步长缩放。每个 ODE 块的输出经可学习的块级残差缩放（`ode_block_scales`，零初始化）后混入主干，属于"可学习动力系统积分器"思想。

### 4.6 预训练预测头：NeuroTwinForecastHead

该模块采用六路特征融合后生成未来预测，核心包括：

- 5 条原有分支：history / latent / temporal / cross_hist / cross_latent
- 第 6 条跨窗口因果注意力分支 `WindowTemporalAttention`（标准多头因果自注意力 + 可学习窗口位置编码 + 零初始化残差门控）
- 融合后通过 `trend_head + shape_head + scale_head` 生成未来信号
- 通过 `IterativePredictionRefiner`（3 轮）做 SC 约束细化

预测构造形式：

`pred = anchor + trend + softplus(scale) * standardized_shape + refinement`

其中 `anchor` 来源于历史末窗与斜率外推，增强短期趋势一致性。

### 4.7 微调病理残差模块：NeuroTwinMoE

`NeuroTwinMoE` 是 finetune 阶段核心，面向病理个体化修正（MoDE 风格）：

1. 路由输入构建
   - 从 `history/latent/base_pred` 提取统计量，形成 `gate_input`（维度 `5*F`，LayerNorm 归一化）

2. 病理嵌入
   - `RicherPathologyProjection` 对单维 HAMD 做多项式扩展：`[x, x^2, sin(pi*x)]` 再投影到 `pathology_dim`（默认 32）

3. 条件路由（RouterCond）
   - 路由仅依赖病理条件（`moe_router_cond_only=True`）
   - 训练默认 multinomial 采样；推理阶段幂次温度缩放（默认 0.3）后采样，可选 argmax

4. 专家族
   - `PathologyResidualExpert`：个体化残差专家（含 FiLM 病理调制、按 `expert_id` 差异化初始化、内部 trend/shape/scale 三头）
   - `SharedPathologyExpert`：始终激活的共享专家（学习通用 MDD 偏移）

5. 残差后处理
   - `IterativePredictionRefiner`（2 轮）进一步 SC 约束细化

6. 输出
   - `delta_pred` 与 `base_pred` 相加得到最终预测；`aux_info` 返回路由概率、top-k 索引、专家负载等信息

## 5. 损失函数与正则化设计

### 5.1 主损失：不确定性加权混合损失

`UncertaintyWeightedHybridLoss` 同时优化四类误差：

- `L_pcc = 1 - Pearson(pred, target)`
- `L_mae = L1(pred, target)`
- `L_diff = L1(diff(pred), diff(target))`（一阶差分一致性）
- `L_std = L1(std(pred), std(target))`（波动幅度一致性）

总损失采用可学习 log-variance 加权：

`L_total = Σ_i [exp(-log_var_i) * L_i + log_var_i]`

其中 `log_var_i` 可学习并可裁剪范围（默认 `[-6,6]`），可看作自动任务平衡机制。

### 5.2 MoE 正则项

训练中额外加入 MoE 正则（`compute_moe_regularization`）：

- Load-balance term：Switch 风格 importance × load，鼓励专家负载均衡
- Z-loss：约束路由 logits 幅度，抑制过度尖锐
- Entropy regularization：抑制路由过度塌缩
- Diversity term：`moe_diversity_weight` 惩罚 batch 内路由决策趋同，鼓励专家多样化

最终优化目标：

`L = L_total + L_moe_regularization`

## 6. 训练策略与工程稳定性

### 6.1 两阶段训练范式

1. Pretrain（HC）
   - `model.pretrain_mode=True`，无 MoE 分支
   - 学习通用脑动力学预测底座
   - 最优权重保存为 `base_best.pt`

2. Finetune（MDD）
   - 加载预训练权重（按 shape 兼容过滤，`load_backbone_weights`）
   - 初期冻结 backbone，仅训练 MoE（`set_finetune_stage`）
   - 达到 `freeze_backbone_epochs` 后逐步解冻 backbone（`backbone_lr_scale` 缩放主干学习率）
   - 最优权重保存为 `finetuned_best.pt`

该策略避免小样本临床数据下 backbone 早期灾难性漂移。

### 6.2 参数组与学习率策略

优化器：`AdamW`

- pretrain：全参数统一学习率
- finetune：`backbone` 与 `moe` 分组学习率（`backbone_lr_scale`）
- 损失权重参数（log_var）可单独学习率比例（`loss_lr_scale`）

调度器：`Linear Warmup + CosineAnnealing`

- 有 warmup 时使用 `SequentialLR(LinearLR -> CosineAnnealingLR)`
- 无 warmup 则直接 Cosine

### 6.3 关键稳定化组件

- AMP 混合精度
- EMA 参数滑动平均（`ModelEMA`）
- 梯度裁剪（`grad_clip`）
- 早停（按验证 `loss_pcc`，`patience` 控制）
- 可复现实验随机种子

### 6.4 MoE 温度调度

`update_router_temperature` 在 finetune 中执行 Hold-then-Decay：

- backbone 冻结期保持较高温度（探索，`moe_gate_temp_start`）
- 解冻后线性衰减到目标温度（利用，`moe_gate_temp_end`）

这与两阶段微调协同，可缓解专家塌缩并改善路由稳定性。

## 8. 论文方法章节可直接参考的表述模板

可直接作为"方法概述"草稿：

> 我们提出一种面向脑动态连接预测的两阶段数字孪生框架 NeuroTwin。
> 第一阶段在健康对照数据上预训练 SC 引导的神经动力学主干网络，主干由结构适配器（DFCAdapter）、双轴多尺度混合器（BrainMDM）和图神经 ODE 积分模块（GraphODEDDI）构成。预测头采用六路特征融合策略，并引入跨窗口因果注意力与迭代图细化机制，以增强未来窗口形态与相关结构一致性。
> 第二阶段在抑郁症数据上进行病理个体化微调：在冻结主干的早期训练病理感知 MoE 残差模块（NeuroTwinMoE），随后逐步解冻主干联合优化。MoE 路由由病理分数嵌入条件驱动，结合负载均衡、熵正则、Z-loss 与多样性约束以抑制专家塌缩。整体损失采用不确定性加权的 PCC-MAE-差分-方差混合目标，实现形态一致性、幅值误差与动态稳定性的协同优化。

## 10. 方法亮点与论文可强调贡献点

1. **SC 先验显式注入 + 可学习图动力学积分**
   通过 DFCAdapter 与 GraphODEDDI 在结构图上执行多阶传播与连续动力学建模。

2. **跨窗口因果注意力增强**
   在预测头与 ODE 核心中引入跨窗口注意力分支，提升跨窗口演化模式建模能力。

3. **病理条件驱动 MoE 个体化残差**
   将病理评分映射为条件嵌入，驱动专家路由与 FiLM 调制，实现个体化修正。

4. **多目标不确定性加权损失**
   以可学习不确定性权重统一平衡相关性、幅值、差分与波动统计约束。

5. **严格 subject-level 评估范式**
   从数据划分层面减少信息泄漏，增强临床任务泛化结论的可信度。
