# NeuroTwin 可解释性实验设计

> 状态说明：本文为实验设计矩阵（设计提案）。其中部分实验已由 [analysis/run_comprehensive.py](analysis/run_comprehensive.py) 与 [analysis/analyze_low_pcc_samples.py](analysis/analyze_low_pcc_samples.py) 实现（见各节"实施状态"标注），其余为待实施设计。文中类名与文件引用已与当前代码对齐（`NeuroTwin` / `NeuroTwinMoE` / `models/neurotwin.py` 等）。

## 1. 实验目标与边界

为系统分析 NeuroTwin 的结构归纳偏置、时空动力学建模能力、预测头解耦机制以及病理感知混合专家（MoE）路由行为，本文设计一套仅基于现有代码框架的可解释性实验。该实验体系不引入新的模型结构、辅助解释器网络或额外训练目标，仅通过 **前向中间量记录、推理期消融、输入扰动、反事实分析与统计可视化** 来解释模型行为。

### 1.1 分析边界

- **仅使用现有模型代码框架**
  - `models/common.py`
  - `models/neurotwin.py`
  - `models/neurotwin_moe.py`
  - `analysis/run_comprehensive.py`
- **允许的分析方式**
  - 前向 hook 与中间状态导出
  - 推理期模块遮蔽 / 分支消融
  - SC 扰动与输入遮蔽
  - pathology score 反事实分析
  - 样本级、ROI 级、组级统计分析
- **不包含的内容**
  - 新解释器网络
  - 新损失函数
  - 新训练目标
  - 替换主干或新增模块

### 1.2 统一实验原则

每项实验尽量统一输出以下四类结果：

1. **全局统计结果**：如平均贡献、平均相关性、平均熵、平均性能变化
2. **分组对比结果**：如 HC vs MDD、轻/中/重抑郁分层
3. **案例可视化结果**：选取代表样本展示中间量变化
4. **消融或扰动结果表**：比较模块关闭前后的 PCC、MAE、std、diff 等指标

## 2. 主干编码器可解释性实验

### A1. BrainRevIN 输入分布稳定化分析

| 项目 | 设计 |
|---|---|
| 实验目的 | 验证 BrainRevIN 是否降低 ROI 间、被试间的幅值偏移，并评估其是否压制病理差异 |
| 分析对象 | `BrainRevIN` |
| 代码落点 | `models/common.py` |
| 操作方式 | 记录归一化前后每个 ROI 的均值与标准差；在推理期增加 identity 模式作为对照 |
| 记录内容 | `mean/std`、归一化前后激活分布、HC/MDD 分组统计 |
| 对照设置 | 正常 RevIN vs 关闭 RevIN（`--norm False` 重建模型即可实现） |
| 核心指标 | PCC、MAE、ROI 方差、组间分布差异、误差-输入方差相关性 |
| 预期解释 | 若 RevIN 有效，应显著降低输入尺度波动，且关闭后性能下降 |

**建议输出图表**
- ROI 均值/标准差箱线图
- HC/MDD 归一化前后分布图
- RevIN 消融性能对比表

## 10. 小结

本节提出的可解释性实验体系完全建立在现有 NeuroTwin 代码框架之上，重点围绕以下四个核心问题展开：

1. **模型是否真正利用了 SC 结构先验？**
2. **模型是否学习到了可解释的连续时空动力学？**
3. **预测头内部的趋势、形状与尺度是否具备明确分工？**
4. **病理感知 MoE 是否实现了与抑郁严重度相关的个体化修正？**

通过前向中间量导出、扰动分析、分支消融、路由追踪及 ROI 级可视化，可以在不改动模型结构的前提下，对 NeuroTwin 的关键设计假设进行系统验证，并为后续论文撰写、可视化展示与错误案例分析提供统一框架。
