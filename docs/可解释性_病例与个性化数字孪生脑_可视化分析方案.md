# 可解释性、病例与个性化数字孪生脑：可视化分析方案

制定日期：2026-10-13。依据当前工作区代码制定；本文件是分析与可视化实施方案，不是分析结果。本次不修改模型、不启动训练、不生成未经计算的效果图。

## 1. 分析对象和现状

主线采用当前脚本中的 `graph_ode + raw + history_fc + personalized`：前缀校准、TFM 历史编码、字段临床条件、固定个人 profile、图动力学持续推进、观测重编码更新、方差读出。旧 `configs/final_model.json` 固定的是单 HAMD FiLM/discrete 模型，不能直接作为新孪生路线的分析配置。

| 能力 | 当前依据 | 分析使用方式 |
|---|---|---|
| 单步、多步、baseline、FC/频谱 | `analysis/next_point_eval.py` | 复用预测和指标；补充逐被试、逐 horizon 的统一导出 |
| 8 字段条件 | `utils/condition_schema.py` | Sex、Age、education、episode、illness、medication、HAMD、HAMA；按真实 mask 和训练统计编码 |
| profile 与个体调制 | `models/tfm_personal.py`、`models/tfm_dynamics.py` | 比较本人 profile 与配对替换 profile，验证其预测作用 |
| 持续状态、更新、双轨迹模拟 | `models/tfm.py`、`inference_twin.py` | `initialize_state/advance_state/update_state` 与 `TwinSession` 接口 |
| 健康参照偏离 | `analysis/twin_reference.py` | HC 训练被试拟合；64 TR 历史产生 ROI × 6 分量标准化偏离 |
| 随访临床读出 | `models/twin_outcome.py`、`train/twin_outcome.py` | 必须有真实访视对及独立训练的 outcome 权重后才使用 |
| ROI 置换与脑图 | `analysis/next_point_eval.py`、`visualize_roi_importance.py` | 现有置换实现未传新版 condition/calibration/profile，须适配后使用 |

本地 `checkpoints/hc_demo_twin`、`checkpoints/mdd_cat_twin` 存在权重，后者有测试 JSON 和 CSV。这只证明文件存在。当前测试报告仍包含全序列 z-score 的旧说明，未记录足以确认孪生路线的完整配置；不能仅凭目录名认定这些结果属于目标路线。本机默认 Python 缺少 torch，本次未完成权重内配置读取、加载或前向验证。实施前读取明确指定 checkpoint 的 `config.args`、条件 bundle、数据划分与实际输入来源，并对应到报告；旧报告仅供探索。

`history_fc` 是可见历史的功能耦合图；现有 Mask 的生成来源不能证明独立解剖 SC。论文和图注中避免把这条路线写成解剖结构连接验证。

## 2. 三条分析主线

1. 可解释性：哪些 ROI、时间片、临床字段和动力学项影响未来预测？
2. 病例分析：模型在谁身上有效、在哪些场景失败，病例的健康偏离与预测依赖有何关系？
3. 个性化数字孪生：个人 profile 是否有增益，持续状态能预测多久，真实观测更新是否改善后续预测？

最终交付是计算结果驱动的图表、可筛选的分析页面及可导出的病例报告。图中“重要性”“健康偏离”“预测误差”保持独立色标与命名，不能合成未经定义的病理分数。

## 3. 数据与统计口径

- 被试是独立统计单位；窗口、锚点和 ROI 的重复测量先在被试内聚合。病例的多个访视不跨 train/val/test。
- 使用同一 checkpoint、合法锚点、预测 horizon、数据尺度和真实目标 mask 比较所有对照；优先 H=1、2、4、8、16，32 TR 仅作扩展预测及短窗 FC 探索。
- 前 32 TR 校准和 profile 只使用当时已观测数据；64 TR 参照历史不能越过分析时点。图只从可见历史生成。
- 持续预测的 profile、临床条件和图按现有实现固定；收到真实观测才更新历史、图和状态。跨扫描重新校准，不拼接不同尺度的序列。
- 以被试级配对 MAE 差为主要效果量，报告 95% bootstrap 区间；重采样整名被试，站点样本足够时站点内分层。ROI/字段的显著性使用被试级配对检验；在预先定义的检验族内做 BH-FDR，不对所有图机械合并校正。
- val 确定扰动方式、可视化阈值及病例选择规则，冻结后统一应用于 test；不能根据 test 图反复选择最好的方法。
- 临床关联报告效应量、区间和 FDR；主要混杂考虑年龄、性别、教育、站点及可用头动。先核对用药/发作类别的临床字典，无法确认时显示原码和 Unknown，不猜类别语义。
- 健康参照目前只校正人口学，没有站点项。先报告站点分层偏离和 HC 留出分布；头动/站点与偏离明显相关时，不能归因于疾病。缺少头动记录时明确标为未控制。
- 正式新增训练遵循已有从零要求：独立输出目录、HC 随机初始化、MDD 仅使用对应本轮 HC，统计量重新在训练被试拟合。已有权重的事后解释不伪称 fresh 实验；本方案不要求为每张图重新训练。

## 4. 可解释性：图与计算一一对应

### 图 1：模型可靠性与适用范围

输入：逐被试模型/persistence/trend/训练集拟合 AR(1) 的单步和多步指标。

- 左：被试级 MAE 配对点图，附模型减 baseline 的差值及区间。
- 中：各 horizon MAE 和 temporal PCC 曲线；明确空间 PCC 与时间 PCC 的区别。
- 右：预测方差/真实方差、误差与基线信号幅度、站点及头动的关系。

用途：先确认值得解释的是有效预测还是误差/塌缩行为。高单步 PCC 本身不能证明长期数字孪生有效；异常高性能须核对锚点、目标切片、被试交集和输入中是否包含未来。

### 图 2：ROI 与时间信息依赖

主分析为扰动后的被试级预测误差增量。

- ROI 依赖：跨被试交换同一 ROI 的完整历史，优先在站点和人口学相近层内选择供体，重复若干随机配对；每名被试同一次配对使用固定供体，避免把窗口当独立被试。
- 时间依赖：按 patch/block 扰动近端、中段、远端历史；保持 context 长度相同。块长度依据当前 patch=4 和实际序列长度预先设定。
- `history_fc` 路线区分两种问题：扰动历史并重算图，得到输入及图的总依赖；固定原图后扰动历史，得到控制图后的历史依赖。后者需要分析接口暴露图输入，不能声称当前脚本已支持。
- profile 默认固定为本人基线，以衡量当前历史作用；基线/profile 的作用在图 4 单独测。不要把改变 ROI 的历史同时改变个人校准当成一个不可拆解结果。

图形：AAL116 脑图 + ROI 排名及区间 + ROI/网络 × 时间块热图。网络标签必须有明确映射版本，不能按 ROI 序号凭空分组；小脑 ROI 单独明确归属。

统计：先按被试得到重复扰动平均误差增量，再检验其是否大于零。现有脚本的 batch t 检验及重复置换增量排序不能直接作为这一方案的有效零假设检验；本次不修改代码。扰动会产生分布外组合，报告供体匹配与敏感性，不称因果病灶。

### 图 3：临床条件依赖与动态响应

固定本人历史/profile，分别交换 8 字段取值及其有效 mask；供体从合理匹配层中取得。HAMD/HAMA 增加联合交换，避免把相关字段的单独扰动解释成独立作用。字段缺失与实际取值分开报告，全部缺失仅作敏感性分析。

图形：字段误差增量森林图；HAMD/HAMA 联合扰动与单字段扰动对照；个体条件响应曲线。

条件扫描只取训练分布支持的范围，固定其他字段，标注为“模型对条件输入的敏感性”。输入 HAMD 与模型响应的关联具有设计依赖，不能当作模型从脑信号独立发现症状的证据；medication 类别切换不代表即时药物疗效。FiLM 权重幅度仅作内部激活描述，不直接作为临床贡献度量。

### 图 4：个体 profile 的作用

同一模型、同一真实未来、同一历史/临床条件，对照本人 profile、站点/人口学匹配其他人的 profile、训练集平均 profile。交换 profile 只换 p，不换供体历史或数据尺度。

图形：本人减替换 profile 的配对 MAE 差；逐被试收益排序；预测轨迹对照。平均 profile 和交换 profile 都是推理敏感性分析；若要论证“增加 profile 结构带来收益”，另外做同预算 personalized=False 的从零训练对照。

检查 p 的维度方差、个人 FiLM 实际调制和扩散率变化；p 分散不等于预测有效。二维 PCA/UMAP 仅作探索、不能用图中分群证明疾病亚型；主结论使用高维距离和预测对照。

### 图 5：动力学解释

在固定真实初始化状态下，导出模型扩散项、非线性残差项及读出轨迹；描述各项随 ROI/时间的范数和个体扩散率。不同 latent 坐标的数值幅度不能直接视为神经活动或“贡献百分比”。

若要分析功能作用，再分别屏蔽扩散项/残差项做前向敏感性对照，报告 BOLD 误差变化；这是训练后扰动，不等于重训消融。图形为网络耦合矩阵、项强度时序、屏蔽前后误差图；attention/A_eff 热图为辅助说明，须与预测变化相互印证。

## 5. 健康参照与病例分析

### 图 6：群体及个体健康偏离

沿用 `analysis/twin_reference.py`：每名 HC 训练被试最早 64 TR 拟合人口学岭回归，对病例得到 116 ROI × 6 描述量残差。六分量为 acf1、acf2、low_power、spectral_centroid、diff_rms、signed_fc_mean；ROI 距离为六分量标准化残差的 RMS。

图形：HC 留出与 MDD 的距离分布、病例 × ROI 热图、个体 ROI × 描述量热图、病例偏离脑图。保留残差正负方向；ROI 距离本身无正负方向。

解释要求：参照训练残差尺度不是正常人百分位，不默认用绝对值大于 2 标“异常”。如需要极端偏离标记，在独立 HC val 上预设经验阈值并在 HC test 报告误报率；同一 ROI 多描述量和 ROI 距离分别明确阈值口径。这是经验参照，不自动升级为校准的规范概率模型。

频谱默认为 cycles/sample；只有确认每扫描真实 TR 后才能转 Hz。64 TR 和 32 TR 轨迹的 FC/频谱只支持短窗描述，不能代替稳定静息态 FC；不同长度须严格同口径比较。

真实历史的偏离与生成轨迹的偏离分开。把真实+生成拼成 64 TR 计算得到的是混合窗口描述，不能当作纯未来健康偏离，也不能把偏离下降称为康复。

### 图 7：单病例完整报告

建议主文 4–6 个病例，按预先指定规则覆盖典型病例、预测增益较大的病例、预测失败病例、高健康偏离病例，以及症状相近但偏离模式不同的一对病例。先用 val 确定选择规则，再按相同规则选 test；不只挑漂亮曲线，所有病例的群体分布位置必须可见。

每页使用同一布局：

| 面板 | 展示内容 |
|---|---|
| A 个体背景 | 匿名 ID、年龄/性别、站点、症状与临床字段缺失；原码含义未确定时不翻译 |
| B 个体动态 | 已观测前缀、未来真实 BOLD、孪生预测、最强 baseline；网络平均及预先固定 ROI，同时显示残差 |
| C 预测能力 | H=1/2/4/8/16 的 MAE、temporal PCC、方差比及其群体分位位置 |
| D 健康偏离 | ROI 脑图及 ROI × 六分量热图，标明参照和分析时点 |
| E 模型依赖 | ROI/时间/临床依赖，以及本人/替换 profile 的预测差异 |
| F 状态更新 | 无更新、周期观测更新、全历史重初始化三条对照及未来误差 |

脑图中高偏离 ROI 不一定也是高重要性 ROI；展示二者散点关系及不一致脑区，作为健康表型与模型预测依据的区分。

病例选择后不再按效果调整 ROI。可先固定三个展示对象：训练/val 全局重要 ROI、该病例偏离最高 ROI、网络平均；每个病例遵循相同规则。单病例窗口差异只作描述，不给伪独立样本显著性。

## 6. 个性化数字孪生的核心验证

### 图 8：持续状态、更新与不确定性

**持续状态预测**：同一初始化历史，完全不输入未来真值，推进 H=1/2/4/8/16；与 persistence、AR(1)、CPM 辅助轨迹比较。graph_ode 和 CPM 必须分别标注，不能混成一条孪生曲线。

**观测更新**：从同一状态做三组：无更新；每 4 TR/8 TR 在当时收到完整真实 ROI 观测后 `update_state`；用同样可见真实历史重新初始化。所有组在更新后相同的未来目标上比较 1/2/4 TR 误差，更新时点自身不计预测收益。前缀/条件/profile 与外部信息一致；加入重新初始化对照后，才能判断持续状态管理是否超出定期重编码的效果。

图形：误差随时间曲线，更新时点竖线，更新后的收益配对图；病例真实/预测轨迹联动。当前更新是历史重编码，不能标为贝叶斯滤波或部分观测同化。

**不确定性**：从 `aux['dynamics_std']` 和对应动态均值导出 ROI/horizon 预测尺度，计算 Gaussian NLL、误差与 std 关系、50%/80%/95% 模型预测区间覆盖率及宽度。必要的尺度校准仅在 val 拟合，test 冻结验证；逐被试汇总，避免大量 ROI/窗口产生虚假的高精度区间。

图形：覆盖率校准图、各 horizon 的覆盖率/宽度，以及病例预测带。未校准标“模型预测标准差”；这是对角方差读出，不代表完整后验、参数不确定性或整条脑轨迹联合覆盖。`forward_dynamics` 的方差只对应其自身同路预测，不能直接搬给长程 `rollout` 或控制轨迹。

**重复扫描/跨访视（有数据才开展）**：重新按每扫描前缀校准，比较 profile 自相似与异人相似、同人匹配识别率、ICC 和本人/交换 profile 预测增益；同时与普通 FC 指纹比较。可比较沿用基线 p 与重算 p，但须在 val 固定策略。单扫描不同窗口只能支持扫描内稳定性，不称跨访视个体身份稳定。跨 seed 的 latent 不直接做坐标距离比较。

### 扩展图 9：个体模拟响应（条件项）

同一初始状态、相同控制序列，生成控制与零控制双轨迹，展示差值时序、网络传播和个人响应差异。固定目标 ROI、幅度与时程，避免从 test 中搜索最优刺激。

没有真实受控数据训练与验证时仅展示“未校准模拟响应”；控制分支有非零输出不证明学到了刺激响应，不能据此推荐靶点、疗程或比较患者疗效。有效驱动 u 不等于 mA/Hz/TMS 电场；需实际物理映射和响应数据才支持相关解释。

### 扩展图 10：纵向结局（条件项）

真实基线—随访对存在、outcome 独立权重已训练时，绘制 HAMD/HAMA 变化真实值—预测值、误差、校准图及个人时间线。必须对照无变化、训练均值变化、仅基线临床/人口学模型，并比较增加孪生特征后的增益。

按被试分组，所有基线特征只来自预测时已知信息。动态模型与参照也不得用随访测试被试的未来数据训练/拟合；基线模拟不能读取真实随访条件/BOLD。TR 级 ODE 不能推进数周来代替临床读出。无纵向数据时，此模块标为待数据，不给虚拟评分。

## 7. 最终可视化交付

### 群体页面

固定顺序：预测有效性 → profile 个性化收益 → ROI/时间/临床依赖 → 健康偏离 → 更新收益与校准。筛选项为 split、站点、匿名病例、horizon、网络、条件缺失情况。

筛选后的展示同时保留全队列总人数、当前样本数和原始分析集合；交互筛选用于探索，不能自动重新生成“显著性结论”。显示效应量与区间，避免仅用显著星号。

### 病例页面

顶部给匿名背景及群体位置；中部联动真实/预测时序与脑图；底部给 profile 对照、健康偏离分量和观测更新。点击 ROI 后更新同一病例该 ROI 的轨迹、偏离和重要性。所有面板保持可见分析时点和来源。

### 导出

- 论文主图：建议图 1、图 2–3 的核心面板、图 4、图 6–7、图 8；图 5 和扩展项按证据充分程度放补充材料。
- SVG/PDF 用于排版，PNG 用于预览；病例报告 PDF；交互 HTML 用于内部检查，默认使用匿名 ID、不给真实个人信息。
- 脑图必须附图谱名称、ROI 编号口径、网络映射、色标单位、是否阈值化、校正方法和样本数。重要性/偏离固定跨病例色标；原始时序与更新区间有明显分隔。
- 不用 3D 动画代替效应量和对照。脑网络动画如需展示，只服务“何时/何处发生变化”，同时保留静态图和可复查数字。

## 9. 实施次序与完成条件

1. 明确当前权重和数据来源，检查结果能对应到该权重；冻结病例选择规则和对照。
2. 导出本人/替换 profile、无更新/有更新/重新初始化的同任务结果；完成图 1、4、8。这是数字孪生分析的核心。
3. 拟合训练 HC 参照并用留出 HC 检查分布；完成图 6 和统一病例页图 7。
4. 适配 ROI/时间/临床扰动，完成图 2、3；动力学项分析图 5 作为补充。
5. 在数据具备时才增加重复扫描、控制响应和临床随访模块。

完成条件：每张图能追溯到实际数据；所有比较使用同一未来目标与有效 mask；有被试级效应量和必要区间；病例包含失败情形；个性化收益、健康偏离、刺激模拟和临床结局分别表述。没有提升也如实交付，不能通过改图或换病例制造提升。

## 10. 方法参考与解释边界

个体健康参照采用群体基准下的个体偏离思路，参考 [The normative modeling framework for computational psychiatry](https://www.nature.com/articles/s41596-022-00696-5)。本项目的岭回归标准化残差不具备该框架所有概率建模和校准能力。

重复测量个体识别参考 [Functional connectome fingerprinting](https://pubmed.ncbi.nlm.nih.gov/26457551/)；它支持设计同人/异人识别比较，不能证明本项目的 profile 已有指纹稳定性。

模型依赖解释不等于疾病因果机制；HC 偏离不等于诊断；共享模型的个体校准不等于独立训练的每人模型；模拟控制差异不等于真实干预效应。这些边界应写在相应图注中。
