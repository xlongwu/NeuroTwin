# NeuroTwin 模型架构详细文档

> 本文依据当前代码（[models/neurotwin.py](models/neurotwin.py)、[models/neurotwin_moe.py](models/neurotwin_moe.py)、[models/common.py](models/common.py)、[main.py](main.py)）核对整理。

## 一、模型概述

NeuroTwin 是一个面向脑功能连接 (dFC) 预测的数字孪生大脑模型，采用 **双阶段训练策略**:
- **预训练阶段**: 健康对照组 (HC) 物理底座训练
- **微调阶段**: 抑郁症 (MDD) 个体化病理专家微调 [MoDE 风格]

### 核心设计理念
1. **图结构约束**: 利用结构连接 (SC) 矩阵引导神经动力学演化
2. **混合专家 (MoE)**: 病理感知的残差专家路由（NeuroTwinMoE）
3. **神经微分方程**: GraphODE 建模脑信号时序动态
4. **多尺度混合**: 双轴（序列轴 + 窗口轴）多尺度特征融合

## 二、输入输出规格

### 2.1 输入数据

| 输入 | 维度 | 说明 |
|------|------|------|
| `x` (历史窗口 BOLD 信号) | `[B, F, W_in, S]` | B: Batch, F: ROI 数量, W_in: 输入窗口数, S: 序列长度 |
| `sc_matrix` (结构连接矩阵) | `[B, F, F]` 或 `[F, F]` | 脑区之间的结构连接强度 |
| `pathology_score` (病理分数) | `[B, 1]` | HAMD 评分（仅微调阶段使用） |

**典型参数值**:
- `num_rois (F)`: 脑区数量（如 116 个 AAL 区域）
- `in_window`: 6（输入窗口数）
- `pred_window`: 3（`main.py` 默认；当前训练脚本中用 1）
- `seq_len (S)`: 30（每个窗口的时间点）
- `total_windows`: 9（总可用窗口数）

### 2.2 输出数据

| 输出 | 维度 | 说明 |
|------|------|------|
| `pred` (预测 BOLD 信号) | `[B, F, W_pred, S]` | 预测的未来窗口 BOLD 信号 |
| `aux_info` (辅助信息) | `Dict` | MoE 路由概率、top-k 索引、专家负载统计等（仅微调模式） |

## 四、核心模块详细说明

### 4.1 编码器组件

#### 4.1.1 BrainRevIN (可逆实例归一化)
```python
输入: [B, F, W, S]
输出: [B, F, W, S]

功能:
- ROI-wise 可逆实例归一化
- 计算每个 ROI 的 mean/std 进行标准化
- 支持仿射变换 (affine_weight, affine_bias)
- 支持反归一化 (denormalize)
```

#### 4.1.2 DFCAdapter (多阶图适配器)
```python
输入: x [B,F,W,S], sc_matrix [B,F,F]
输出: [B,F,W,S]

结构:
- learnable edge_logits [F,F]: 可学习的边权重
- alpha: 残差混合系数
- self_loop: 自环强度
- order_logits [3]: 多阶混合权重 (0阶/1阶/2阶)
- SEChannelGate: 通道注意力门控

计算流程:
1. SC 矩阵对称化 + 可学习边加权
2. 添加自环并归一化 (D^{-1/2} A D^{-1/2})
3. 多阶图传播: x0 + x1 + x2 (混合权重可学习)
4. 通道门控 + 残差连接
```

#### 4.1.3 BrainMDM (双轴多尺度混合器)
```python
输入: [B, F, W, S]
输出: [B, F, W, S]

分支结构 (共 8 路融合):
1. 原始输入
2-3. seq_branches: 深度可分离 Conv2d(kernel=(1,3)) 与 (1,5)
4-5. win_branches: 深度可分离 Conv2d(kernel=(3,1)) 与 (5,1)
6. _pool_along_s: 序列轴多尺度自适应池化
7. _pool_along_w: 窗口轴多尺度自适应池化
8. cross_branch: 1×1 卷积交叉融合

融合: Conv2d(8F→2F) → GELU → Dropout → Conv2d(2F→F)
      → SEChannelGate → GroupNorm → 残差
```

#### 4.1.4 GraphODE / GraphODEDDI
```python
GraphODEDDI:
- ode_steps: 6 (默认, ODE 积分步数)
- Heun/RK2 二阶积分 + 可学习步长缩放 step_scale
- stochastic_depth_rate: 0.1 (随机深度正则)

GraphODE (动力学函数 f(t, h, sc), 4 分支 sigmoid 门控融合):
├─ input_norm: LayerNorm
├─ ROI 图注意力 (SC 约束):
│   ├─ Q/K/V 投影到 hidden_dim
│   ├─ SC 作为 hard mask + soft bias (log1p)
│   └─ Multi-head Attention
├─ temporal_branch: 深度可分 Conv2d(1×3) 时序卷积分支
├─ window_attn: 跨窗口 MultiheadAttention (window_heads=5)
└─ FFN: Feed-Forward Network

积分方法: Heun/RK2 (二阶龙格-库塔)
  k1 = f(t, h, sc)
  k2 = f(t, h + dt*k1, sc)
  h_new = h + step_scale * dt * 0.5 * (k1 + k2)

主干集成: 每个 GraphODEDDI 块输出经 ode_block_scales
（零初始化可学习参数, sigmoid 门控）残差混入:
  x = x + sigmoid(scale) * (evolved - x)
```

### 4.2 预测头 (NeuroTwinForecastHead)

#### 4.2.1 WindowTemporalAttention (跨窗口时序注意力)
```python
输入: [B, F, W, D]
输出: [B, F, W, D]

结构:
- MultiheadAttention (num_heads=4, 因果 mask)
- pos_embed: 可学习窗口位置编码
- gate: 可学习残差门控 (零初始化)

功能: 显式建模 W 个窗口间的 dFC 时序演化依赖
```

#### 4.2.2 六路特征融合
```python
1. history_feat: history → LayerNorm → Linear → GELU
2. latent_feat:  latent → LayerNorm → Linear → GELU
3. temporal_feat: Conv1d(kernel=5, groups=F) → GELU → Linear
4. cross_hist: Conv1d(kernel=1) → GELU
5. cross_latent: Conv1d(kernel=1) → GELU
6. win_feat: WindowTemporalAttention 分支

fusion: Linear(hidden*6 → hidden) → GELU → Dropout
```

#### 4.2.3 三头预测
```python
trend_head: 捕捉长期趋势
  LayerNorm → Linear → GELU → Dropout → Linear

shape_head: 捕捉形状/形态（末层零初始化，稳定训练起点）
  LayerNorm → Linear → GELU → Dropout → Linear
  → standardize_future (标准化)

scale_head: 捕捉幅度尺度（末层 bias=-2, 初始输出偏小）
  LayerNorm → Linear → softplus

预测公式:
  anchor = 基于历史末窗与斜率的外推 (每步 +0.5*slope)
  pred = anchor + trend + scale * shape
```

### 4.3 MoE 模块 (NeuroTwinMoE)

#### 4.3.1 RicherPathologyProjection
```python
输入: pathology_score [B, 1]
输出: pathology_embedding [B, pathology_dim]  # 默认 32

多项式特征扩展:
  poly = [x, x², sin(πx)]  # 捕获线性/非线性/周期效应

投影网络:
  Linear(3 → inner_dim) → GELU → Linear(inner_dim → pathology_dim)
```

#### 4.3.2 RouterCond (条件路由器)
```python
输入: gate_input [B, gate_dim=5F], pathology_embedding [B, pathology_dim]
输出: router_mask, top_k_indices, router_probs, true_probs

路由策略:
├─ 训练: multinomial 随机采样 (高熵探索)
├─ 推理: 幂次温度缩放后采样 (inference_temperature=0.3)
└─ 可选: use_argmax=True 硬 topk

专家容量限制:
  capacity = batch_size * top_k / num_experts * capacity_factor
```

#### 4.3.3 PathologyResidualExpert (路由专家)
```python
输入: latent, history, base_pred, pathology_embedding
输出: delta_residual [B,F,W_pred,S]

结构:
├─ history/latent/base 三路特征投影 (按 expert_id 差异化初始化)
├─ cross_roi: Conv1d 跨 ROI 融合
├─ Fusion: cat(4 路) → Linear
├─ FiLM 条件化:
│   film(pathology_embedding) → gamma, beta
│   fused = fused * (1 + 0.1*tanh(gamma)) + 0.1*beta
└─ 三头输出: trend + scale * shape
```

#### 4.3.4 SharedPathologyExpert (共享专家)
```python
始终激活，捕获通用 MDD 病理模式

结构:
├─ LayerNorm → SwishGLU 门控 MLP
│   (gate_proj * SiLU(up_proj)) → down_proj
└─ path_gate: per-ROI 病理调制 (初始化为恒等)
```

### 4.4 迭代细化模块

#### 4.4.1 IterativePredictionRefiner
```python
输入: pred [B,F,W,S], sc_matrix [B,F,F]
输出: delta_residual [B,F,W,S]

多轮级联细化 (n_rounds=3 for 预测头, 2 for MoE):
每轮:
  ├─ 图传播: g1 = A_norm @ pred, g2 = A_norm @ g1
  ├─ 局部卷积: Conv2d(1×3)
  └─ 融合: Conv2d(3F→2F→F)

轮次权重: round_scales 逐轮递减 (sigmoid 初始化)
```

## 六、模型特点与创新点

### 6.1 架构创新

1. **SC 引导的神经动力学**
   - GraphODE 使用结构连接作为图注意力掩码和偏置
   - 多阶图传播捕获不同阶数的脑区关系

2. **双轴多尺度混合**
   - 显式分离序列轴和窗口轴的处理（8 路分支融合）
   - 多尺度自适应池化捕获不同时间尺度特征

3. **跨窗口时序注意力**
   - 因果自注意力建模窗口间演化
   - 位置编码捕获时序顺序语义

4. **病理感知的 MoE**
   - 多项式特征扩展丰富单标量病理信息
   - FiLM 条件化实现病理特征调制
   - 共享专家捕获通用模式 + 路由专家捕获个体差异

5. **迭代细化机制**
   - 多轮 SC 约束的残差修正
   - 逐级消除预测系统误差

### 6.2 训练策略

1. **双阶段训练**
   - 阶段 1: HC 预训练学习健康脑动力学（权重存为 `base_best.pt`）
   - 阶段 2: MDD 微调，仅训练 MoE 模块(前期)，后期解冻主干（权重存为 `finetuned_best.pt`）

2. **温度调度**
   - Hold-then-Decay: 前期固定高温，后期线性降温

3. **不确定性加权损失**
   - 同时优化 PCC、MAE、差分、标准差
   - 可学习的不确定性权重自动平衡各任务
