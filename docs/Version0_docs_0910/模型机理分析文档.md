# 论文图组级模型机理可视化分析方案

> 状态说明：本文为**设计提案，尚未实施**。文中描述的 `mechanism_visualization_analysis.py` 入口与各模块 `forward_debug` 接口均未在当前代码中实现；引用的类名已与当前代码对齐（`NeuroTwin` / `NeuroTwinForecastHead` / `NeuroTwinMoE`）。与现有 [analysis/run_comprehensive.py](analysis/run_comprehensive.py)（指标评估、MoE 路由统计、置换重要性、显著脑区）互补：该工具负责 faithfulness/sanity 与统计结果，本方案负责内部机制可视化。

## Summary

目标是新增一套"机制证据链"可视化，而不只是 ROI 排名或扰动结果。方案面向论文主图/补图，采用轻量 debug 接口扩展，不改变训练逻辑、不改变默认 `forward` 行为。

最终产出一个独立入口 `mechanism_visualization_analysis.py`，生成：
- 结构先验机制图
- 时序动力学机制图
- 预测头分解图
- MoE 病理个体化图
- 成功/失败案例对照图
- `mechanism_report.md` 和所有中间 `json/csv/npz`

## Key Changes

- 在 `models/*.py` 增加可选 debug 路径，默认训练/推理行为完全不变：
  - `NeuroTwin.forward_debug(...)`
  - `DFCAdapter.forward_debug(...)`
  - `BrainMDM.forward_debug(...)`
  - `GraphODEDDI.forward_debug(...)`
  - `NeuroTwinForecastHead.forward_debug(...)`
  - `NeuroTwinMoE.forward_debug(...)`

- `forward_debug` 返回：
  - `pred`
  - 原始 `aux_info`
  - `debug_trace` 字典，包含模块中间量、分支范数、残差分解、路由概率、FiLM gamma/beta、ODE step 轨迹等。

- 新增 `mechanism_visualization_analysis.py`：
  - 复用现有 dataloader 和 checkpoint 加载逻辑。
  - 默认使用验证集。
  - 默认 `torch.no_grad()`。
  - 默认临时开启 MoE argmax routing，降低可视化随机性。
  - 输出目录为 `analysis/outputs/mechanism_visualization/<run_name_timestamp>/`。

## Figure Design

- **Figure 1: Overall Mechanism Trace**
  - 输入、SC、RevIN、DFCAdapter、BrainMDM、GraphODE、ForecastHead、MoE residual 的模块级流程图。
  - 每个模块旁标注输出范数、贡献量、性能变化。
  - 用于解释模型整体"从结构先验到病理修正"的机制链。

- **Figure 2: Structural Prior Mechanism**
  - 原始 SC、top-k SC、DFC learned edge、GraphODE attention 的热图。
  - SC perturbation 下的 `ΔMAE/ΔPCC` 条形图。
  - network-level sensitivity matrix：网络内/网络间连接删除后的性能变化。
  - 结论问题：模型是否真的利用结构连接，而不是把 SC 当弱噪声。

- **Figure 3: Temporal Dynamics Mechanism**
  - 输入窗口遮蔽曲线：早期/中期/最近窗口对预测的影响。
  - GraphODE 每个 block、每个 integration step 的 `k1/k2/delta_h_norm` 轨迹。
  - Refiner 每轮 delta 范数和边际收益曲线。
  - 结论问题：模型是否做了稳定动态演化，而不是普通残差堆叠。

- **Figure 4: Forecast Head Decomposition**
  - 六路特征贡献：history、latent、temporal、cross_hist、cross_latent、window_temporal。
  - 六路特征 cosine redundancy matrix。
  - `anchor + trend + scale * shape` 分解曲线，展示若干代表 ROI。
  - 结论问题：预测头是否具备趋势、形状、尺度的可解释分工。

- **Figure 5: Pathology-Aware MoE Mechanism**
  - HAMD counterfactual expert routing curve。
  - shared residual vs routed residual 的贡献条形图。
  - expert × brain network residual heatmap。
  - FiLM gamma/beta 随 pathology score 的变化热图。
  - 结论问题：病理变量是否真正驱动个体化修正。

- **Figure 6: Success vs Failure Case Cards**
  - 选取 top-PCC 和 low-PCC 样本各若干。
  - 对比 SC 敏感性、窗口依赖、ODE 稳定性、MoE 路由熵、预测头分解、主要误差 ROI。
  - 输出失败模式标签：结构依赖弱、时序相位错配、MoE 路由不确定、refiner 过平滑。

## Implementation Details

- Debug 接口只在显式调用 `forward_debug` 时生效；现有 `forward`、训练脚本、checkpoint 加载不受影响。
- 所有大矩阵默认只保存样本均值、top-k、网络聚合结果；原始全量中间量用 `--save_raw_trace True` 才保存。
- 默认分析样本：
  - 全验证集计算 baseline 和样本 PCC。
  - 机制图默认抽取 `--trace_samples 32`。
  - case cards 默认抽取 high-PCC 3 个、low-PCC 3 个。
- AAL/network 映射：
  - 若提供 `--aal_file`，输出脑区名和网络名。
  - 未提供时使用 `ROI_0 ... ROI_115`。
- 与现有 [analysis/run_comprehensive.py](analysis/run_comprehensive.py) 互补：
  - 该工具负责指标评估、路由统计、置换重要性与显著脑区（faithfulness/sanity）。
  - 本方案负责内部机制可视化。

## Test Plan

- 接口不变性测试：
  - 同一 batch 下比较 `model(x, sc, pathology)[0]` 与 `model.forward_debug(...).pred`，要求 `allclose`。
  - `forward_debug` 不应改变 `model.training` 状态。
  - debug 模式下不产生梯度。

- 快速烟测：
  ```bash
  python mechanism_visualization_analysis.py --help
  python mechanism_visualization_analysis.py \
    --data_root <data_root> \
    --finetuned_weight <checkpoint> \
    --trace_samples 8 \
    --max_eval_samples 32 \
    --skip_raw_trace True
  ```

- 输出检查：
  - 必须生成 `mechanism_report.md`
  - 必须生成 `figures/figure_1_overall_trace.png` 到 `figure_6_case_cards.png`
  - 必须生成 `debug_trace_summary.json`
  - 必须生成 `case_cards.csv`

- 科学有效性检查：
  - SC perturbation 图应显示 original 与 shuffle/identity/zero 的性能差异。
  - ODE/refiner 曲线不应全为 0 或 NaN。
  - Forecast head 分解中 `anchor/trend/shape/scale` 能重构预测头输出。
  - MoE counterfactual 中 expert probability 随 pathology grid 有可解释变化。
  - low-PCC case cards 应显示至少一种可归因失败模式。

## Assumptions

- 不重新训练模型。
- 不改变 checkpoint 格式。
- 默认以验证集作为机制分析对象。
- 默认输出论文可用静态 PNG，同时保存 JSON/CSV 方便后续重画。
- 第一版不做 3D 脑表面渲染；ROI/network 图先用热图、条形图、矩阵图和 case card 表达。
