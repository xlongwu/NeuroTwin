# 研究状态与未解决问题

本轮实验已收尾，最优工作模型为完整H32监督的S2 + Graph-ODE + CPM。
结果与负结论见 [EXPERIMENTS.md](EXPERIMENTS.md)，正式结果见
[results/final](../results/final/README.md)。当前没有自动执行的研究任务。

## 未解决问题

1. 远期时间对应偏弱；表征、自由推进、读出与未来不确定性尚未分离。
2. 单seed与探索性val结果不足以建立跨seed、站点和真实纵向访视稳健性。
3. HAMA/HAMATotal、缺失编码、诊断来源及真人—访视映射仍待来源核实。
4. 概率轨迹联合依赖、真实刺激响应及稳定个体机制尚未验证。
5. CPM物理删除与训练加速、CUDA/compile跨进程逐位续训仍未验证。

## 后续边界

以上是候选问题，不是待执行清单。优先复用保留的最优权重、机器汇总和有限冻结分析；
出现明确且有实用价值的信号后，才按新的具体请求决定训练范围与预算。
不为每个微小差异重新完整训练/微调，不自动追加seed、扫权、test或连续研究链。
D1使用未来观测，不能把其表现当成自由预测可达到的性能界限。
