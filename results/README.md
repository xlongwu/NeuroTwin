## 协议

| 协议 | 说明 | 用途 |
|---|---|---|
| `fixed_anchor_H1_8` | 单个 K64 锚点一次前向输出 H1–8，未来真值不反馈；每被试 8 个锚点 | 多步外推、FC、CRPS/Variogram |
| `rolling_one_step` | 每个 TR 用真实观测历史预测下一点并拼接；K64 历史、前 32 TR 校准 | 跟踪能力；不是自主生成 |

- HC test 222 人，MDD test 225 人；被试名单与 `data/subject_split_pretrain.json`、`data/subject_split_finetune.json` 的 test 一致。
- 先被试内平均，再跨被试等权；FC 使用严格上三角 6,670 条边。
- MDD 微调模型使用 mdd8 条件；HC 参照在 HC/MDD 数据上使用 hc3 条件。两者条件不同，不能直接解释为疾病效应。
- H9–32 与长程自主生成已停止训练和评价；H32 历史结果不属于当前结果。

## 解释边界

- 固定锚点 H1–8 的 FC 在 8 TR 短窗上估计，噪声较大；不能与滚动全序列 FC 的 0.997 量级直接比较。
- 滚动协议每个 TR 重新输入真实历史，不能代表自主生成或长期自由运行能力。
- CRPS 与 Variogram 只在固定锚点 H1–8 上计算；滚动缓存没有 sigma，不能定义概率评分。
- Variogram 的预测/真实 FC copula 都是显式 plug-in，不是模型原生联合分布。
- HC 与 MDD 的数值差异均为描述性，未做组间显著性检验，不能直接解释为疾病效应。
- 单步与短程预测质量不证明疾病定位、真实有效连接或刺激响应有效性。
