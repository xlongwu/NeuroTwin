# Profile 补充探索

固定参考向量在每组分别由该组 checkpoint 的 profile 编码器处理全零、32 TR 校准信号得到。它是确定的模型尺度参考，并不等于“没有个体信息”。实际历史、前缀校准与条件固定，仅将 profile 换为该向量，比较 8 个抽样锚点 H1 预测；先对人内锚点平均，再对人等权描述。HC/MDD 参考向量范数分别为 5.403/5.406，实际测试 profile 范数范围分别为 5.447–5.641 和 5.442–5.643；但两组参考向量均有 27/32 个维度落在对应测试集逐维范围之外。这提示参考可能存在分布偏移；仅凭测试集范围无法判定训练分布覆盖，也不能视为有效的中性对照。

HC 参考减原 profile 的 MAE 差在被试间均值为 -0.000108，MDD 为 -0.000148；输出绝对差相对于原输出绝对值的被试中位数分别为 0.00254 和 0.00204。该比值先在人内对全部锚点与 ROI 取绝对差均值，除以相应原始输出绝对均值，再跨人取中位数。与原始 profile 缓存的最大差均为零。

另对每人的扫描序列按 32 TR 非重叠切片，保留最早 32 TR 的原有校准尺度，分别计算 profile；之后的片段只作为事后描述，不用于预测对照。两组每人有 4–7 段，包含首段；与首段比较的间隔范围均为 32–192 TR。先对每人后续片段与首段的 profile 相关取均值，再跨被试求中位数，HC/MDD 分别约为 0.99846/0.99844。profile 的多个维度接近固定值，公共方向可能使相关性偏高，因此不能据此宣称个体识别、跨扫描重测稳定性或神经特异性。后续片段并非模型训练时的固定前缀位置，属于分布外探索。

为解释上述较高相似性，额外计算同组测试集中每人首段 profile 与其他人的首段 profile 的 Pearson 相关：每人先平均与其他被试的相关，再跨人取中位数。HC/MDD 全组参照分别为 0.99576/0.99439；只与同站点其他被试比较时分别为 0.99858/0.99855，有同站点参照的被试为 218/222 和 222/225。参照限定于各自测试组，未纳入自身；它是描述基线，站点人数不同，不能用来确认身份稳定性或站点因果作用。这些较高的跨人相关进一步说明，单看高扫描内相关不足以证明个体特异性。
