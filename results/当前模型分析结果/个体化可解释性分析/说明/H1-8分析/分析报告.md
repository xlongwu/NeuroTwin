# H1–8 分析记录

本记录引用已有的完整测试集结果，并记录新增分析的完成状态。固定锚点与滚动单步是不同协议，不能互换。已有结果目录未覆盖。

## 核心预测与功能连接

基于已有逐被试测试结果，固定锚点 H1 的 MAE 为 HC 0.090648、MDD 0.091969；H8 分别为 0.811023、0.801787。三项指标的逐 horizon 均值和被试间标准差见 [图01](../../../多步预测分析结果/图片/H1-8分析/图件/图_预测指标_H1-8_被试等权.pdf) 和 [表01](../../../多步预测分析结果/表格/H1-8分析/核心指标/表_预测指标_H1-8_被试等权.csv)。每组每个 horizon 分别有 222 人、1776 个任务和 225 人、1800 个任务；方向准确率排除真实变化不超过 0.05 的点。阴影是被试间标准差，不是置信区间。

已有 H1–8 FC 结果中，组均值边相关为 HC 0.982368、MDD 0.982881，单锚点边相关分别为 0.603448、0.601232。短窗 FC 的单锚点结果不能由组均值替代。频谱与概率结果及其限制见 [现有评估汇总](../../../多步预测分析结果/说明/H1-8当前结果/评估汇总/评估汇总说明.md)：单锚点 PSD log MAE 为 0.5643、0.5715；整体覆盖率掩盖了不同 horizon 的校准差异。所有 HC/MDD 比较仅为描述性结果。

滚动误差的 [ROI 与网络图](../../../单步预测分析结果/图片/H1-8分析/图件/图_误差结构_滚动单步_被试等权.pdf)、[站点图](../../../单步预测分析结果/图片/H1-8分析/图件/图_误差结构_滚动单步_站点.pdf)、[逐 ROI 表](../../../单步预测分析结果/表格/H1-8分析/可解释性/表_误差结构_滚动单步_逐ROI.csv)、[网络表](../../../单步预测分析结果/表格/H1-8分析/可解释性/表_误差结构_滚动单步_网络.csv) 和 [站点表](../../../单步预测分析结果/表格/H1-8分析/可解释性/表_误差结构_滚动单步_站点.csv) 使用已有测试缓存；站点图和表保留每组样本数，部分站点只有一两名被试。网络由项目 AAL116 表定义，先计算个体网络均值再跨被试等权，误差线是被试标准差。改善度先对每个被试计算，再跨被试平均。源 ROI 误差均为有限正数。此项仅用于预测质控，两组使用不同权重，不能解释为疾病效应。

误差表中的 `n_samples` 是所纳入被试的滚动锚点总数，并非独立被试数；各锚点之间存在重叠，组均值仍按被试等权。

## 来源核对

两份 checkpoint 哈希与方案一致，滚动 FC 汇总记录的 checkpoint 和划分文件哈希均与当前文件一致；三个滚动测试缓存的被试集合分别与对应划分相符。结果见 [来源核对](../../../多步预测分析结果/中间产物/H1-8分析/核心指标/原始_来源核对_20261028.json)。

MDD 微调滚动缓存清单写有 hc3，但现有滚动脚本的清单字段被固定写为 hc3。对 IS001-1-0001 使用当前权重和 mdd8 条件重新计算，预测与已有缓存最大绝对差为 0.000001669；对全部 225 人的 mdd8 条件使用重算，逐被试 MAE 与缓存汇总最大差为 0.000000502。这些证据支持清单字段误标，但 MAE 比对不能证明所有锚点的预测完全一致。已有测试评估 JSON 的预处理 caveat 仍描述旧的全序列标准化，与当前 checkpoint 中的 raw 前缀校准配置不一致，因此该段元数据不能作为当前数据来源的证明。

条件使用脚本原先将批次平均的 FiLM 和 AdaRMS 范数赋给批内所有被试；混合被试批次会污染个体统计。已改为按被试条件计算，并用混合被试批次测试验证。预测前向和权重未改变。

HC val 的条件使用分析已完成：222 人、25,290 个滚动锚点。完整条件与全缺失条件的预测差除以真实变化尺度，被试中位数为 0.00435，均值为 0.00430（标准差 0.00140）。两种条件的 MAE 均值分别为 0.092918 和 0.092369；ODE FiLM 范数及其被试标准差见 [条件使用汇总表](../../表格/H1-8分析/可解释性/表_条件使用_滚动单步_被试等权.csv)，编码器 AdaRMS 范数不可用。参数范数不等同输出贡献，以上只描述 HC val 当前字段和 lag-1 协议，不代表临床效应或因果关系。

MDD test 使用微调权重和 mdd8 条件，225 人、25,366 个滚动锚点。相对预测差中位数为 0.00411，均值为 0.00448（标准差 0.00132）；完整条件和全缺失条件 MAE 分别为 0.092031 和 0.091797。[MDD 汇总表](../../表格/H1-8分析/可解释性/表_条件使用MDD_滚动单步_被试等权.csv)列出范数和样本数。HC 与 MDD 此处的划分、权重和条件字段均不同，不据此解释组间差异。

## 健康参照偏离

HC val/test 负控在 116 ROI 和 7 个网络各自进行 BH-FDR，均无显著项。预先固定的 1,504 对、36 站匹配比较中，逐 ROI 和网络均无 FDR 显著项；全脑平均差为 -0.0200，配对 bootstrap 95% 区间为 -0.0489 至 0.0091。匹配被试平均绝对偏离的方差比为 1.022，配对标签交换检验 p=0.906。完整队列和仅 test 的未匹配 ROI 检验均无 FDR 显著项。参见 [组间检验记录](../../中间产物/H1-8分析/病理分析/原始_组间偏离_20261028.json)、[匹配 ROI 表](../../表格/H1-8分析/病理分析/表_组间偏离_滚动单步_匹配ROI.csv)和[匹配网络表](../../表格/H1-8分析/病理分析/表_组间偏离_滚动单步_匹配网络.csv)。当前协议下未发现稳定的组间 ROI 偏离；这一结果不是疾病机制结论。

原全训练集 z 参照文件中的 `conformal_q` 来自拟合残差，并非独立校准集分位数，不能据此声称覆盖率保证；该分位数未参与 z 评分和组间检验。另已建立[独立分割校准参照](../../中间产物/H1-8分析/病理分析/健康参照_训练分割校准_20261028.npz)：仅使用 HC train，以 seed=2024 分为 1,422 人拟合和 356 人校准，取 90% 分位对应的有限样本秩。它与全训练集 z 参照是两套独立产物；覆盖保证依赖交换性，尚未评估测试集覆盖率，也不能自动外推至 MDD。

匹配清单跨 train/val/test，HC train 使用交叉拟合评分，故匹配结果不是独立 test 专属结论。未匹配检验使用站内置换；其中仅共有站点的被试参与置换统计量，表中另列的整体均值差未作站点调整。站点覆盖数见机器记录。

探索性的[临床关联表](../../表格/H1-8分析/病理分析/表_临床关联_滚动单步_网络.csv)使用匹配 MDD 被试，控制年龄、性别和站点；HAMD 有 1,504 人，HAMA 完整观测有 422 人。p 值未经多重校正，不用于替代主要终点或作因果解释。

六描述量基线的匹配 ROI 检验和 HC 负控均无 FDR 显著项，最大绝对差为 0.05955。该基线中 HC train 被试对描述量参照为样本内评分，而模型的 HC train z 使用交叉拟合，因此数值对照有此限制。静态 FC 岭回归仅在 HC/MDD train 上进行站内分层五折 OOF，AUC 为 0.5660；它不是独立 test AUC，也未用于模型选择。[描述量记录](../../中间产物/H1-8分析/病理分析/原始_描述量基线_20261028.json)；[静态 FC 记录](../../中间产物/H1-8分析/病理分析/原始_静态FC岭回归_20261028.json)。

## 输入与历史敏感性

[ROI 重要性](../../图片/H1-8分析/图件/图_ROI重要性_固定首锚点_被试等权.pdf)在每组完整 test 的首锚点，固定每个被试的非自身供体，依次替换各 ROI 的 K64 历史，同时保留目标条件、校准和 profile。116 个 ROI 的被试等权 lag-1 MAE 增量范围为 HC 0.00908–0.01307、MDD 0.00851–0.01256；[汇总表](../../表格/H1-8分析/可解释性/表_ROI重要性_固定首锚点_被试等权.csv)包含批均值标准差和标准误，未进行 FDR 检验。这些是扰动敏感性，不是疾病定位。

[历史顺序图](../../图片/H1-8分析/图件/图_历史归因_H1-8_被试等权.pdf)与[逐被试热图](../../图片/H1-8分析/图件/图_历史归因_H1-8_逐被试.pdf)采用 8 个连续块、每块 3 次固定随机序列，首锚点完整 H1–8；曲线为被试均值，阴影为被试间四分位范围。最后一块置换还改变最后观测值，其影响不能全归因于时间顺序。

[输入扰动图](../../图片/H1-8分析/图件/图_输入扰动_H1-8_被试等权.pdf)对首锚点每个源 ROI 的最后 8 TR 分别加减 0.1；HC/MDD 全部 447 人的 sham 最大差均为 0。图中响应矩阵排除自响应以显示跨 ROI 变化，时间曲线包含自响应；完整响应矩阵保存在数据文件。它只表示模型结构敏感性，不是实际刺激、损伤或治疗响应。

[异质性图](../../图片/H1-8分析/图件/图_异质性_滚动单步_测试集.pdf)展示 test 被试的平均绝对 z 和逐 ROI 剖面。独立测试集的[短序列一致性表](../../表格/H1-8分析/可解释性/表_短序列一致性_H1-8_逐被试.csv)与[profile PCA](../../图片/H1-8分析/图件/图_个体profile_固定首锚点_PCA.pdf)使用首个 H1–8 锚点；PCA 两组分别拟合，不能直接比较其坐标。profile 分半仅反映同一扫描的 32 TR 分段一致性，不能解释成跨扫描重测稳定性。短窗 FC 身份匹配、ACF 只作探索，未扩展 profile 组间检验。

## 执行状态与限制

- HC val 滚动单步 B4 已通过：完整 222 人、25,290 个锚点，被试等权模型 MAE 为 0.092918，persistence 为 0.604840；以组均 MAE 之比计算改善 84.64%，单侧配对符号翻转置换 p=0.00009999（10,000 次，seed=2024）。[门槛记录](../../../单步预测分析结果/中间产物/H1-8分析/病理分析/原始_B4门槛_20261028.json)。
- HC train 健康参照已拟合（1,778 人、116 ROI）；HC train 采用 10 折交叉拟合评分，HC val/test 与 MDD train/val/test 评分已完成。HC val/test 负控采用站点内 10,000 次置换、seed=2024，ROI 和网络分别进行 BH-FDR，均无显著项，满足 ROI 负控继续条件。[负控记录](../../中间产物/H1-8分析/病理分析/原始_健康负控_20261028.json)。两组共有站点 38 个，进入统计量的 HC val/test 分别为 220/210 人；单组站点不参与置换统计量。
- 匹配和未匹配组间检验、临床偏相关、六描述量与静态 FC 基线及 test 异质性描述已执行。模型显著 ROI 数为 0，未超过描述量基线显著 ROI 数的 0，因此不满足 T2 条件，不启动 profile 组间扩展。
- 已执行当前权重的首锚点学习图、ROI 置换、H1–8 历史归因、扰动和探索性 profile/短序列一致性；这些首锚点结果不代表所有锚点。HC val 和 MDD test 条件使用量均已完成。

已有 B7 脚本不能直接作为本方案的完整实现：其中负控置换次数上限为 2,000、网络 bootstrap 次数上限为 5,000，网络 q 值逐网络单独计算，离散度 p 值检验的是配对均值差而不是方差比。本次上述组间、描述量和负控结果采用新增脚本，分别执行 10,000 次置换与配对 bootstrap、网络族 FDR 和方差比置换。

原有匹配清单覆盖各数据划分；MDD test 中有 137 人在该清单内，但其中只有 11 人的既定匹配 HC 也在 HC test。不能临时重新匹配或把这 11 对直接当作完整匹配队列，需区分跨划分匹配与独立 test 结果。

新增图表的复现命令：`python -m analysis.h18_horizon_figure` 和 `python -m analysis.h18_rolling_error_structure`。源数据是已有逐被试测试 CSV/NPZ；图表与数据表输出到本目录，采用方案中的编号和命名格式。

组间检验依次使用 `python -m analysis.h18_negative_control`、`python -m analysis.h18_group_tests`、`python -m analysis.h18_clinical_correlation`；基线使用 `python -m analysis.h18_descriptor_baseline` 和 `python -m analysis.h18_fc_ridge`。可解释性原始推理使用 `analysis.h18_graph`、`analysis.h18_probes` 和 `analysis.h18_importance`，其中后两者分别对 hc/mdd 指定组和设备；汇总使用 `analysis.h18_probe_summary`、`analysis.h18_importance_summary` 及 `analysis.h18_short_sequence`。完整参数和缓存协议见各脚本及对应数据清单；重复运行前应保留现有结果。
