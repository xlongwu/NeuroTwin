## 口径与结论

- 当前模型的滚动单步预测精度高，但每个预测点都重新输入真实 K64 历史，不能代表连续自主生成精度。
- 自由 H32 只在最早 K64 后一次预测未来 32 TR；中途不更新真值。样本为原站点匹配的 20 对 val/test 被试，并非完整独立 test 评价。
- HC 参照权重的辅助训练时程为 8 TR，H32 是外推。现有样本的时间 PCC 较低且 R² 为负，尚不支持长程轨迹重建良好的结论。
- MAE/RMSE 为最早 32 TR 固定校准后的 BOLD 尺度，不是原始扫描强度单位。R² 在每位被试内展平全部时间点和 ROI 后计算。
- 时间 PCC 先逐 ROI 沿时间计算再平均；空间 PCC 先逐时点跨 116 ROI 计算再平均。FC PCC 比较每人的两张 FC 矩阵的 6,670 条上三角边。
- 变化量相关比较预测变化与真实变化；方向准确率只统计真实绝对变化超过 0.05 的点。
- 本次重新计算的 MAE、FC PCC、谱形 KL 已与对应既有结果交叉核对通过。
