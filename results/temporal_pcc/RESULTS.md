# Temporal PCC 补充实验结果

TP0 为原 E2，TP1 在 E2 上增加固定权重 0.05 的两头 Temporal PCC 之和。
两臂使用相同 HC 起点、seed=2024、划分、模型与非 Loss 超参数，225 名 test 被试、
相同预测锚点和 H=8。CPM 与 ODE 各用自身 mask；只使用预测的未来点，至少 3 个有效点，
真实轨迹方差不超过 1e-8 时排除，预测恒定时仍监督。以原验证 ODE MAE 选优。
TP0 在 43 轮、TP1 在 31 轮早停；训练、评估及配对统计均已完成。

| 指标 | TP0：E2 | TP1：E2 + Temporal PCC |
|---|---:|---:|
| t+1 MAE | 0.08066734 | 0.08063608 |
| ODE H1–H8 MAE | 0.53289543 | 0.53294750 |
| CPM H1–H8 MAE | 0.53326342 | 0.53350778 |
| ODE H8 MAE | 0.80251914 | 0.80255400 |
| ODE Temporal PCC | 0.70562083 | 0.70604755 |
| CPM Temporal PCC | 0.70750744 | 0.70761189 |

ODE Temporal PCC 增加 0.00042671（相对 0.0605%，68.9% 被试改善，配对 p=5.08e-13）；
CPM Temporal PCC 增加 0.00010445（相对 0.0148%，63.6% 被试改善，p=7.39e-7）。
相关性目标有响应，但改善幅度很小。

ODE 平均 MAE 恶化 0.00977%（p=0.319），CPM 平均 MAE 恶化 0.04582%（p=3.66e-17）；
ODE H8 略差，p=0.785。t+1 MAE 改善 0.03874%，ODE H1–H2 改善 0.04117%，
但 ODE H4–H8 恶化 0.01644%；CPM H1–H2/H4–H8 分别恶化 0.14516%/0.02532%。
不能将相关系数增加解释为总体预测能力提升。

**本轮判定：不纳入正式 E2，继续保留原损失基线。**
结论限于本轮固定权重、H=8、单 seed 和原 checkpoint 选优协议；未开展权重搜索或多 seed，
不能据此认定所有 Temporal PCC 设计均无效。

完整指标见 `compare/summary.csv`，绝对差值、相对改善、被试改善比例与配对检验见
`compare/paired_vs_control.csv`。本报告没有引入架构、频谱或概率模型调整。
